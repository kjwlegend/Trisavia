## 1. 一条可以逐步交付的路线

先让小岚有稳定身份和可持续管理方式，再让它取得有权看的世界内容；以后分别增加自愿互动、本地学习和真实履约。每次增加一种能力，都先明确它拥有的事实、访问用途、拒绝条件和兼容办法，再接页面 / 宿主。不能为了将来可能用到，先给注册模块添加空订单、记忆库或通用工作流。

本轮统筹转交的WS02—05只读约束已纳入：独立世界读取、互动与履约不同状态、成长三轴与本地隐私、独立条件账本。它们是架构输入，不是活动类型、服务类型、认证、币或宿主选型已获批准。

上述顺序是按阶段推进的架构路线，不是实施排期或新任务卡。契约 / 设计样例先行、局部实现后交集成、最后补真实宿主 / 恢复 / 体验证据，不能让领域实现等待平台终验，又让平台终验等待领域实现。WS06、WS07按当期切片进入，不作为需要先做完的第六 / 第七阶段。

WS01以后仍可能因human、多个世界、管理关系变化和新授权范围而修改查询 / schema / 适配。目标是避免把新业务写入身份核心，不承诺“以后完全不用改注册模块”。更换模型或宿主可沿同一身份，但同时运行多个实例、转让 / 合并居民、跨实例迁移需单独设计。

## 4. 版本、长期离线与自部署

至少分别识别服务 / API语义、事件模式、接入说明、宿主能力、数据schema、来源用途规则和活动 / 服务规则版本。一个发布号可以关联它们，不能用它替代所有版本判断。能力发现告知当前支持范围、所需版本、退役 / 升级提示及恢复代次；功能可用不代表调用者获授权。

| 变化 / 客户端情况 | 建议兼容办法 | 禁止的隐含升级 |
| --- | --- | --- |
| 同语义新增可选字段 | 旧读者可以忽略；必需语义另声明最小版本，测试生产者 / 消费者矩阵 | 给旧字段换含义，或用缺省值假装客户端已确认 |
| 新活动 / 对象 / 成长类型 | 类型与规则 / 格式版本明确；旧客户端只显示获准通用摘要，无法安全理解则停止相关读取 / 动作并提示升级 | 未知成长类型自动加载、未知业务状态按“完成”处理 |
| 破坏性API / 事件变化 | 显式新语义版本、迁移说明和已选择的兼容窗口；安全可转换的才做边缘适配 | 永久维护两套状态机；通知改版导致旧客户端静默丢进度 |
| 长期离线后回来 | 先取能力 / 当前授权，检查说明版本与游标有效性；窗内续读、超窗快照和当前事项重建并标缺口 | 凭旧说明 / 缓存继续写入，逐个补跑错过的周期，重新注册掩盖兼容失败 |
| 旧未决命令 / 过期回执 | 保留形成时的代次 / 载荷；查原尝试和现状，不明外部效果先核对，再明确生成新动作 | 换Token或改操作号后自动重做，尤其服务外部工作 |
| 凭据轮换 / 权限撤回 | 身份稳定，当前授权与数据访问即时校验；旧会话 / 页令牌按政策失效 | 把有效旧游标当授权；让迟到收据恢复停用版本 |
| 自托管实例升级 | 实例固定自己的协议 / schema / 能力清单；升级前核对支持组合、备份、迁移和宿主文档；离线演练不依赖中央遥测 | 实例升级自动信任另一实例身份或接收跨实例业务 |
| 实例从旧备份恢复 | 旧授权 / 游标 / 命令代次失效，保留业务事实；按当前首期提案拒绝灾备再授权 | 用恢复时生成的新记录证明旧授权有效，自动创建替代居民 |

兼容窗口、退役通知时长和支持版本数量待选择，不能无限承诺离线客户端永远兼容。管理员选择不升级时应知道停留版本的能力边界；协议不支持时保留能安全提供的只读 / 导出说明，不能为可用性绕过认证。停用新功能先阻止新命令，再依原域处理未决事项；不能关掉路由就把履约或冻结余额丢在半途。

## 5. 数据迁移、备份与保留

建议未来迁移采用“先扩展兼容结构 → 可核对回填 → 切换读写 → 验证 → 到期移除旧结构”。每次列受影响域、schema / API / 应用版本组合、数据量、回填重试与撤销边界；WS06单一序列执行，各域确认语义。不是任何升级都能直接回滚旧程序：旧读者无法解释新状态时，先停相关写入并修复 / 前滚，不拿旧备份覆盖新业务。

身份和绑定回填不得凭显示名、主人自报或新生成代次重建管理权；迁移必须保留稳定ID、授权来源、撤销 / 消费和原回执关联。跨域外键 / 索引是存储约束，不授予消费者直接写权。备份以同一恢复点覆盖当前业务、授权、回执、事实及已采用的附件；本地产物不在平台备份内。恢复代次和权威授权证据问题沿用现有WS01 / WS06边界，未建设备份外最新授权服务。

| 数据类别 | 保留 / 删除的所有者与维护要求 |
| --- | --- |
| 身份、成员、管理绑定与证明校验材料 | WS01定义生命周期，WS06执行；退出 / 暂停 / 撤销 / 删除分别处理，旧授权不能因备份或迁移复活 |
| 操作回执 / 去重、通知、当前事项 | 回执至少覆盖承诺重试窗口；通知可过期，当前事项按原域有效性保留，游标前移不删除待办 |
| 正文、公开投影、最小事实 / 审计 | 源域决定用途 / 保留，WS02清理读模型；事实可保留允许的最小引用 / 结果，但不因此保留全部正文或敏感标题 |
| 本地成长原材料、派生方法与收据 | WS04追踪来源修订 / 用途 / 派生影响，宿主负责清理和回退；平台只记成功 / 待处理 / 未知，不能保证离线删除 |
| 服务材料 / 案件 / 条件账本 | WS05定义用途与证据保留；案件读取不恢复普通联系；账本若采用，历史纠正追加来源记录，不编辑成另一笔账 |
| 研究 / 案例材料 | WS07按独立同意与退出规则处理；产品加入、私有摘要同步和公开案例不是同一授权 |

具体时长和永久删除范围仍待真实试用前决定。源撤回先阻断新访问和受影响复用，再执行投影 / 派生清理；投影重建只重建仍获准且仍存在的源，不能从历史回执找回已撤正文。内容治理隐藏与物理删除也不相同，保留理由和范围须能说明。

## 6. 用扩展演练检验维护成本

以下是未来设计 / 契约和实现阶段的验收题，不是已新增功能。每次记录修改模块、公共契约差异、是否触碰身份核心及原因；若需全域改动，先解释边界问题，再决定重构，不能硬守“零改动”口号。

| 演练（来自本轮域约束） | 局部增加的位置 | 必须证明的结果 |
| --- | --- | --- |
| M3“数字艺术作品”进入既有空间 / 标签关注 | WS03来源，WS02类型 / 可见性适配及展示 | 范围内有界读取；分页中改标签 / 撤权不漏仍可见项、不交付失权正文；移出缓存；离线窗内续读 / 超窗标缺口；网页不推进Agent进度 |
| 新“双轮文本共创”活动 | WS03活动类型 / 规则版本 / 贡献阶段；复用收件和提交端口 | 注册核心无需因活动而增字段；旧反馈按旧规则结束；重复接受只建一个活动，乱序 / 过期动作拒绝，旧通知不能绕撤权 |
| 新“摘要引用核查流程”成长类型 | WS04本地处理器 / 格式版本与独立评价协议，平台最小收据 | 旧客户端不加载未知类型；未见样本及延迟试用达到预登记标准才可复用；来源撤回阻止后续复用并记录清理，拒传仍完成本地闭环 |
| 新“翻译校对”服务 | WS05材料 / 成果 / 验收规则和所属页面，范围外副作用另授权 | 身份核心不因服务内容变化；并发选择 / 重复确认只有一单；撤权拒绝受保护动作，屏蔽保留合法最小案件入口；无币完整运行 |
| 新宿主或HTTP说明改可选MCP | WS06适配、能力记录和版本化说明 | 同一主体 / 用例 / 回执，秘密和作用域不扩张；真实手动 / 周期能力分列，无新服务器推理 |
| 2D列表 / 轻量空间更换为3D风格 | 渲染 / 资源和必要展示适配，不改变业务端口 | 相同权限事实与核心操作，减少动画 / 文本路径保留；世界规则、成员和接受 / 验收不随视觉改变 |

描述字段的新增可采用受控模式注册；有新权限、期限、参与者或外部效果的能力必须显式业务实现并送审。不开放任意远程代码插件，也不允许上传活动JSON就绕过业务状态检查。扩展点是受控端口和类型约定，不是运行未知代码的许可。

## 7. 未来的质量门禁、诊断和贡献流程

| 验证层 | 有意义的检查内容 | 负责与证据 |
| --- | --- | --- |
| 领域模块 | 状态守卫、当前授权 / 版本 / 期限、并发选择、不可逆终态、字段锁 | 原域；输入 / 预期 / 实际及源版本，避免只测一遍实现内部调用 |
| 契约 / 兼容 | 生产者与消费者样例、旧 / 新版本、未知类型、无权 / 不完整 / 待生成区别 | 原域契约owner、WS06整合；一次故障不能被“空列表”掩盖 |
| 数据 / 故障 | 原子回执、丢响应、重复 / 乱序、撤销竞争、固定分页基线、迁移升级 / 失败恢复 | WS06基础与原域；真实库 / 夹具分列，灾备拒绝不冒称成功再授权 |
