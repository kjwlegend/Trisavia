# Pixel Crawler · 第一轮选材

已完整盘点用户新增目录：**372 文件，181 PNG、190 Aseprite、1 Terms**。本目录是原生素材的选材与尺度试验；未生成替代美术，未修改原素材、角色资料、正式地图或生产代码。

[打开可视化选材页](http://127.0.0.1:59197/docs/design/pixel-crawler-selection-20261027/)。页面含待机/行走预览、原生大小与当前人物对照、两个扩建区域的新增陈设开关、18项可筛选场景素材。

## 先用哪些

| 顺序 | 素材 | 能改善什么 | 当前限制 |
|---|---|---|---|
| 1 | 灌木/花丛/岩块/长椅/路灯 | 林园、河湾与外街的空地和边缘细节 | 先小片配套；轮廓比 Sunnyside 深，根部碰撞与冠层遮挡要单列 |
| 2 | 绿发平民、酒馆人物 | 普通居民和服务人物更容易辨认 | 已有侧向待机4帧、移动6帧；未发现配套的上/下方向成品 |
| 3 | 长桌、柜架、床、地毯、窗户、烤架 | 酒馆、书屋、旅舍的独立室内视觉方向 | 适合成组搭建；不代表当前已有可进入室内或新增业务容量 |
| 4 | 兜帽旅人、铠甲人物、法袍人物 | 特殊外观与角色轮廓差异 | 奇幻倾向明显，需与世界定位协调；现有 Run 不能凭名称当成完整步行动作 |

实际选出 **5款不同的现成人物 + 2款兽人风格储备 + 18项场景素材**。骷髅、武器与大型工业设备不作为本轮优先项。

## 两个关键发现

**Tavern_A 和 Tavern_B 不是两款不同造型。** 逐像素比对 Idle、Walk、Idle_Hold、Walk_Hold 四组导出PNG，RGBA完全相同，页面已合并。源文件目录仍原样保留；不把重复素材算作角色丰富度。

**64×64是帧画布，不是人物身高。** 当前选用的 Sunnyside shorthair 样本真实非透明高度16px（脚底 y39）；新平民/酒馆为30px（脚底 y48），骑士等约29px且Idle与Run画布不同。页面在同一脚底线上给出1:1与缩到16px的对照。直接缩小会丢失五官/服装细节，不能简单把PNG换入现有角色模板。

建议角色上线前逐款确定：可见身高、脚底pivot、Idle/Walk方向、镜像规则、头顶气泡锚点、行为动画回退。未补齐前先做固定服务人物的视觉试验；不把侧向镜像称为四方向。Avatar身份、选择与保存仍归WS01；生产接线由TD安排原工程作者。

`Body_A` 有14组动作（待机、走、跑、搬运、采集、钓鱼、浇水及战斗等），但本身是未穿衣底稿；`New_Version` 的6个源文件是彩色结构人形，已按原生RGBA与帧时长导出供检查，并非成品新角色。它们可以支持后续角色模板制作，不能直接列成可选外观。

## 场景试摆与实际接线

林园/外街两张试摆复用上一版扩建图。新植物和设施保留原像素颜色、描边和细节；只演示组合，尚未计算碰撞、合法站位或服务条件。现有道路、钓位和NPC坐标不因试摆改变。

- 优先低风险静态装饰；不要将新深色道路/建筑瓦片零散混入全镇。
- 树根/灯柱/桌腿是碰撞候选，树冠按脚底Y遮挡；花与地毯可作为平面细节。
- 营火/烤架只有局部循环，示意不授权新增制造、采集、烹饪操作；真实活动动画仍需现有权威状态。
- 作者随包 `MockUps/Tavern.png` 仅作为**作者原始室内参考**展示，不署作我们的原创稿，也不当作已实现空间。

## 资产与出处

`selection.json` 是本轮所选素材入口，含源路径、源SHA、切片矩形、导出SHA、帧数/尺寸/时长、可见包围盒与脚底建议。`source-inventory.json` 是完整原目录盘点；`new-version-export.json` 记录6个Aseprite无重绘导出。切片不重着色、不增加纹理；路灯切片剔除了同图集旁边独立备用灯笼，原对象像素保持。

工程依赖：先落实人物方向/比例模板，再接身份选择；场景小包先选林园/外街装饰并由地图作者核坐标/碰撞。当前没有发布到UAT，没有将素材选择视为用户最终审美签收。
