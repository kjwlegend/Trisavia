# 四区世界地图：精细图片与独立叠层

2026-10-25 · 新设计候选，供用户审核。体验入口：<http://127.0.0.1:59669/>。

用户认为原四区地图过于粗糙，要求显著提升精细程度，可采用图片 + 描边 + 打点。此次完整替换设计预览的地形表现，保留原四区 / 11 地点的中文内容、ID、开放规则，不修改生产或 UAT。标题与打开入口沿最新 0.3.1 口径统一为「地图」。

## 视觉分层

1. **地形底图：**使用内置 imagegen 生成真实 raster 图，不再由 SVG 山、树、地形色块拼出底图。海岸礁湾、浅水层、森林、山脊、农田、河流、河口、小镇分别可辨。西部群岛 / 中央草原 / 东方河岸 / 北方山地仍是一幅连贯世界。
2. **区域描边：**四条独立 SVG 路径，普通态轻描、选中态暖金描边，hover 有细亮边。路径是选区范围，含邻近海域，不是物理碰撞、行政边界或精确测绘海岸线。SVG 只承担叠层，不绘制地形。
3. **地点与标签：**11 个独立 DOM 按钮，清昼小镇使用绿色双环；未来地点为空心。默认只给当前镇显示地点名，选择其他地点时展开其标签，避免全图文字堆叠。四区名称持续可见。
4. **观察界面：**沿用奶油纸张、灰绿文字和细框。地貌缩略图与真实地点列表在右侧；正文 14/24，标题 24/34。未来地区仍能浏览介绍，进入按钮明确禁用。

`欣赏底图`隐藏边界、地点和标签；缩放支持 100%–250%，放大后拖动。这个比例是显示缩放，**不是声称原图具有 4K 分辨率**。图像实际为 1536×1024；100% 是完整地图适配，放大不会生成新的图像细节。默认框体维持完整 3:2 比例；窗口变窄时侧栏可滚动，不通过压小正文字号塞下内容。

## 数据和工程边界

- 保留 `sunset` / `plain` / `dawn` / `north`。11 地点中文名称和 ID 不变；唯一可进入的是 `qingzhou-town → worldId default`。图上的未来建筑、道路、码头是世界设想，不能推导为已开放服务。
- 新底图的实际地貌与原 SVG 不同，因此 UI 百分比锚点已重新对齐。**使用新图必须同时使用新叠层；不能继续用旧 anchor 或旧 SVG 的 `land-*` 路径。**
- 全部坐标属于这张插画的展示空间。与 M3 的 `/world-map-life-v1.json`、真实小镇格子、NPC 位置、寻路和 runtime mapId 没有替代关系。图中小镇是宏观象征，不是当前小镇建筑布局的精确缩略图。
- 原始 PNG 的 SHA 与生成文件一致；JPEG 是单纯编码派生。先装载图，失败时显示明确错误。地图仍按用户打开时延迟加载，不增加世界轮询或后台动画；生产可以先加载 JPEG，PNG 留作设计母版。
- 布局 / 图片 / SVG / DOM 必须共用同一个 3:2 viewport 和变换。文字、标记尺寸在放大时保持可读，离开可见区域的标记退出键盘 Tab 顺序。定位当前镇恢复全貌并选中当前镇。关闭 / Escape 恢复入口焦点。
- 地图入口保持当前产品第 6 个 HUD 的「地图」语义；本预览不复制 HUD 或覆盖 0.3.1 已完成的入口调整。无生产接线、版本号修改、真实移动或发布动作。
