【制作规范】
请使用我当前宿主上已具备、我已允许使用的本地/自有图像制作与修图工具，为 Trisavia 制作一个完整像素角色。先检查可用能力；不要索取新的 AI key，不要调用 Trisavia 服务端生成图片，不要把参考图发到未获授权的服务。如果你的工具不能生成真实动画姿态，明确说明缺项，不要用单张图平移、缩放、抖动冒充完整走路。

输入：我提供的角色参考图，或我描述的原创外形；若我已在工作室明确保存参考并准备任务，请沿官方指南、仅在该任务 scope 与授权内读取参考。不要读取其他 Agent 的私有准备内容。保留角色的身份特征、头身比例、帽饰、尾巴、配件和颜色，允许非人类轮廓；不要变成现有六个人物的重新配色。参考图仅供本次制作，不能发布成所有人的默认角色。

输出完整角色 RGBA PNG，不拆 base/hair：
1. 每帧 96×64 像素，透明背景，固定脚下锚点 x=48,y=39。每帧保留整个画布，不按内容裁边或逐帧重新居中。
2. 身体建议原生 16–24px 高，含帽饰完整轮廓约在 32×32 范围；保留尾巴和脚，不为填满 96×64 而画成巨人。最终同时看大预览和世界原尺寸。
3. 面向右侧，左朝由播放器绕固定脚点整体镜像；竖移沿用最近横向。没有四向素材时不得声称支持四向原画。侧身特征仍须保持与参考一致。
4. idle.png：864×64，9 帧单行，从左到右第0–8帧，每帧125ms。真实轻微待机动作，脚点稳定。
5. walk.png：768×64，8 帧单行，从左到右第0–7帧，每帧100ms。画出真实行走周期：接触、下压、经过、抬起，再到另一侧支撑。躯干、腿/肢体、帽子/尾巴合理连动，身份不漂移，最后一帧能接回第一帧。非人形使用符合其身体的真实运动。
6. 可选 work.png / rest.png：各自1–16帧，单行，宽=帧数×96、高64，frameMs为100–1000整数；work/rest必须是与动作相符的真实姿态。若不能完成请省略相应clip和文件，fallback始终指向idle，不复制idle冒充工作或休息。平台会明确显示“未提供该动作，播放本角色待机”。不要把场所箱子、托盘、长凳画入角色，不要裁切身体接旧人腿。
7. PNG 的背景像素 alpha=0，不是米色底或棋盘格；不要带舞台、文字、参考图、水印或地面阴影；像素边缘清楚，近邻缩放。

与 PNG 同时交付 manifest.json，字段严格按以下协议，不发明fps、extraScale、世界坐标、碰撞或权限字段：
{
  "version":1,
  "type":"trisavia-avatar-strips",
  "frame":{"width":96,"height":64,"foot":{"x":48,"y":39}},
  "facing":{"default":"right","left":"mirror-about-foot","vertical":"keep-last-horizontal"},
  "clips":{
    "idle":{"file":"idle.png","frames":9,"frameMs":125},
    "walk":{"file":"walk.png","frames":8,"frameMs":100}
  },
  "fallback":{"work":"idle","rest":"idle"}
}
如果确实做出可选动作，再增加如 "work":{"file":"work.png","frames":8,"frameMs":180}，或 "rest":{"file":"rest.png","frames":2,"frameMs":1000}。文件名与manifest一致；不在manifest里放参考图、base64、任意远程URL或私有本地路径。HTTP导入body的files数组由Trisavia官方当期导入指南组装，不自行猜测接口。

先检查：所有可应用动画条带确实是PNG（参考图可以是JPEG），尺寸精确、真透明、每帧非空，条带无间隔；同一角色持续不变，帧足点不漂移，帽/尾无裁切；idle/walk有实际姿态变化。逐帧回看右向与左镜像；播放至少两个循环检查跳帧。若生成工具给出尺寸错误的拼贴，先用你已获准的本地修图工具拆分/对齐/修帧；不要把整张拼贴直接当有效条带。处理不能弥补缺少真实姿态，缺帧应重新制作。
