# 自定义 Avatar 设计包

本轮核心是素材规范与本地 Agent 创作／上传／管理／校验接口；素材仅所属用户使用。停止追加编辑器 UI，必要页面仅保留导入、预览、状态和管理。

已完成的历史版式示意（不是当前编辑器开发需求）：<http://127.0.0.1:63301/>。页顶切换空稿／检查失败／待确认／已应用等示意状态；中央实际播放仓库原有角色的待机／行走，检查比例、间距及操作布局。未连接真实账号，不是已实现的自定义形象功能，不把原角色称为用户的企鹅帽成品。

- `CONTRACT.md`：本轮短视觉／素材／交互合同，已对齐 TD / A 的唯一 manifest v1。
- `manifest.template.json`：最小配置模板；不附合格上传包，不含私有参考图。
- `generation-prompt.txt`：交给用户自有 Agent / AI 工具的完整准备任务读取、制作、具名上传、真实校验及按当前形象权限应用／交回 Owner 的指令。
- `index.html` / `studio.css` / `studio.js`：保留的历史工作室版式，停止扩展；真正素材导入与权限流程归 A / D，合法工程样例归 B。
- `assets/`：现有内置角色的原字节 PNG 比例参照，来源见 `assets/SOURCES.md`，不随公开自定义模板分发。
- `reference/`：此前浏览器截图；`validation.json` 保留此前示意验证的历史范围，不作本轮 API、权限矩阵或生产完成证据。

生产流程：有当前形象直接修改权的 Agent 可经 `avatar_assets.tasks.create` 自建本人任务并上传获准 PNG/JPEG 参考；Owner 网页准备只是可选入口，无直接修改权时沿 Owner 显式有限任务 → Agent 用本人 runtime 读取任务获准参考/模板 → 自有 AI 制作 → 具名上传成品并查真实校验 → 必要动作预览 → 按当前 avatar 权限应用；允许 Agent 直接修改时可经 API 应用本人授权素材，owner-only 则交回 Owner。仅无上传能力时交文件并明确未上传；也可直接手动导入已有完整素材。聊天确认不修改实时权限；不对已有 Agent 直接修改权额外强加网页确认。已有操作结果未知时查原回执，不另建任务绕开。任务到期／撤回不回滚已合法应用事实；Owner／绑定授权变化后停止旧成品的新公开读取，新 Owner 不继承原素材使用权。世界／个人管理／公开资料使用同一形象引用。

设计基线 `767a65c1`；独占分支 `codex/docs-custom-avatar-20261025`，仅本目录。私有企鹅帽 JPG 已看过但不存入本包；地图精修是另一独立批次，不随本包整合。无服务端生成、额外 AI key、真实上传/应用、版本修改或生产/UAT发布。
