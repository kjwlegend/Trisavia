# 自定义角色：视觉与素材合同 v1

2026-10-25 最新范围：以素材规范、开放接口和用户本地 Agent 创作／上传／管理／校验为交付核心；素材仅其所属用户使用，不增加公共素材库、分享或跨用户套用。停止扩展角色编辑器、绘画及复杂帧编辑 UI；页面只承担必要导入、预览、状态和管理。TD 已确认基础帧约束；本目录仅设计合同与模板，不代表 API、存储或上线已经实现。当前实际渲染依据为 `767a65c1` 的 `look.js`、`human.js`、`life-art.js` 与 appearance-v1.1。素材解析字段跟随 A 的唯一协议；B 负责真实合法可导入样例与面向外部 Agent 的生产指引。

## 角色素材

参考输入支持常见 PNG / JPEG（.jpg / .jpeg），包括用户当前 JPG；参考图无需透明。下表的透明 PNG、帧尺寸与条带限制仅适用于可应用动画成品，不套用到参考图。

| 项目 | 固定要求 |
| --- | --- |
| 形式 | 完整角色 RGBA PNG 动画帧；帽子、尾巴、配件与非人形身体均属于角色，不套内置六款换色或 base/hair 分层 |
| 网格 | 每帧 96×64；同一动作一张水平连续 strip，左至右从 0 开始；不留格间距、无自动裁边、无每帧重新居中 |
| 脚点 | 固定 (48,39)，相对于帧左上角；世界绘制原点减去该值。不是 (48,64) 的旧工程画布原点。帧中的透明留白必须保留 |
| 朝向 | 原画面向右，左朝将完整角色围绕脚点镜像；竖向移动沿用最近横向。首版不伪称具备四方向素材；禁止角色、帽子分别镜像 |
| idle 必需 | 9 帧，125ms/帧，即 8fps；864×64。允许呼吸、眨眼、配件小动作，但脚点不漂移 |
| walk 必需 | 8 帧，100ms/帧，即 10fps；768×64。至少有接触、下压、经过、抬起及相反支撑的真实姿态；肢体、躯干、配件保持同一角色 |
| work / rest 可选 | 分别声明有无。缺失时播放该角色的 idle，并保留真实「工作中／休息中」文案；不切回内置角色、不声称有工作／坐下动画 |
| 世界权威 | 外观不改变服务器位置、路线、脚下排序依据、格子占用、碰撞与动作权限；显示动画不提交移动或触发工作 |
| 透明与像素 | 真透明背景，禁止烘入米色/棋盘格、文字、水印、舞台、地面阴影；近邻采样，不平滑像素，不按每帧 alpha 边缘缩放 |

视觉比例指引：身体通常与现有人物接近，约 16–24 原生像素高；帽饰等完整轮廓建议控制在 32×32 内、地面基准 y=39。横向尾巴可适度扩展，不能因大画布将角色画成 96×64 巨人。该比例是美术目标，不新增后端硬拒绝阈值；最终须同时预览「1×世界比例」与大图。宽尾、圆体、无双腿生物使用其真实运动方式，不强迫人类腿部结构。

减弱动态/暂停使用相应有效 clip 的固定帧。资源加载失败应呈现明确的加载错误／中性占位及重试，不冒用其他内置角色。完整 walk 缺失、空白或结构不合规阻止应用；仅有参考图不算可用素材包。机械校验不能宣称已判断步态自然：本地制作工具或必要预览应逐帧检查接地、身份连续、帽尾完整和循环衔接，不强制使用网页编辑器。完全相同帧可检测拒绝；单帧平移、缩放和反复抖动仍需视觉检查，不能借字节不同冒充动作完成。

现行 Life 的人类 rest 使用上半身裁切加腿部资产，自定义角色不得复用。自定义 work/rest 有素材时按其完整帧播放，无素材时保留 idle。场所已有箱子/托盘/长凳属于世界对象；不要把对象同时烘进角色造成重复，不为贴合自定义角色任意移动脚点或补人腿。

## 必要页面与接口边界

页面只保留所选 Agent／所属素材、导入、动作预览、校验与任务状态、必要管理及获准的应用／恢复操作。播放和查看帧用于检查真实动作，不增加画笔、像素编辑、复杂时间线或在线补帧。既有三栏工作室样稿只作历史比例参考，不是本轮待实现的编辑器需求。

- 参考输入支持 PNG／JPEG。Owner 选择文件后先本地预览，明确准备后才私有保存；已有完整素材可直接导入。网站不做服务端 AI 生成，不要求额外 AI key。
- 主要复制入口给本地 Agent 非秘密任务定位。Agent 使用本人有效 runtime，读取获准材料与模板、创作、具名上传、查询真实校验和管理本人获准素材；无上传能力才交文件并明确未上传。接口与授权必须由 A / B / WS01 的真实实现和指南裁定，设计提示不新造端点或权限。
- 检查反馈具体说明文件／帧／期待与实际；结构检查不宣称步态自然，不输出虚假视觉质量分数。未完成的 work/rest 如实显示回退。
- 导入、校验和预览不等于应用；应用、替换与恢复按当前 `avatar` 修改权限执行，不以“自定义素材”为由新增所有人一律网页确认的限制。具体权限矩阵按下方 WS01 §3.4 已更新裁定。
- 人类页面用「参考图」「让我的 Agent 制作」「预览动作」「应用形象」「恢复内置形象」，不要求人填写 manifest、assetRef 或权限代次。失败保留原已应用形象，切换 Agent 不串用未提交输入。

应用权限遵循 [WS01 §3.4](../../workstreams/ws01-registration/02-features-and-flows.md#34-自定义动画形象2026-10-25-短合同)，仅将最终裁定映射到设计文案：

| 当前主体／权限 | 应用、替换、恢复 |
| --- | --- |
| 当前 Owner | 管理本人所管 Agent，并核对素材归属与目标 |
| 本人 Agent：`agent_autonomous`，`avatar` 未锁，`saveProfile.allowed=true` 且 `writableFields` 含 `avatar` | 具名 API 可应用本人用户、绑定本 Agent 的有效素材；恢复内置沿同一权限，不新增网页确认门槛 |
| `owner_specified` / `proposal_required` / `avatar` 锁定 | Agent 不直接应用，保留原 Owner 确认路径；上传／校验不解锁或自动接受提议 |
| 其他 Owner／Agent、无有效关系／任务，或未获操作权限 | 不因知道 ID、摘要、URL 或上传过文件而获得素材使用或管理权 |

所有操作仍按具名接口重验凭据、当前管理关系、任务范围、暂停／平台限制、资料／政策版本及原公开资料条件。当前世界自主开关不替代资料模式；不新增通配权限。素材持久关联所属用户、目标 Agent、origin/instance，同 Owner 的其他 Agent 也不自动获得使用权；新 Owner 不继承前 Owner 私有原图／草稿。已应用成品可用于既有角色展示，但匿名可见、内容去重或公开引用都不授跨用户选择／应用／复制归属的权利，不建设公共素材库或分享。接口尚未接线只能报告未实现，不能把工程缺口写成业务强制网页确认。

同一份版本化形象在世界、个人管理、公开资料中使用同一播放器和脚点；缩略图按固定包围视窗显示整个角色，不单独裁掉帽子/尾巴。头像尺寸差异仅为显示缩放，不改变真实外观。

## 设计预览边界

`index.html` 是已完成的历史工作室版式和状态示意，停止扩展，不作为当前生产范围或接口完成证据，也不连接真实 Agent/API。画面使用仓库原有短发角色的真实 idle/walk PNG 作为比例参照，不将其称为企鹅帽或新自定义作品；原 PNG 仅原字节复制，来源在 `assets/SOURCES.md`。参考图本地选择后仅通过 Object URL 在此页面显示；不上传，不持久保存。示意按钮不能代表后端验证或实际保存，导入检查/应用状态由页外评审工具显式切换。

用户提供的企鹅帽 JPG 已实际查看，只作轮廓/身份参考；不复制进仓库、不作为公开默认形象、不作为大家共同样例。最终用户参考角色的制作由其本地 AI 执行。工程可导入样例由 B 另交，不能混同此版式参照。

## 与 A / TD 已冻结的唯一协议对齐

TD 2026-10-25 直接确认采用 A 的 v1 字段；`manifest.template.json` 原样使用此协议。`version:1` 表示格式版本，不是上传次数；`type:'trisavia-avatar-strips'`；`frame.width/height=96/64`，`frame.foot={x:48,y:39}`；`facing={default:'right',left:'mirror-about-foot',vertical:'keep-last-horizontal'}`。动作条目是 `{file,frames,frameMs}`，不另存 fps，播放速率由 `1000/frameMs` 派生。

必需 idle/walk 如上。可选 `work.png` / `rest.png` 均为 1–16 帧、每帧 100–1000ms，单行宽度为 frames×96。1 帧可以表达真实静止工作/休息姿态，但不可声称有动态动画；必需 walk 仍必须 8 帧真实运动。`fallback:{work:'idle',rest:'idle'}` 固定存在，未完成可选素材直接省略 clip 和文件，不能复制 idle 假冒完成。

HTTP 上传 body 的 `files` 数组独立于 manifest，按同名 PNG 对应；具体编码/权限/配额/端点由 A 的实现合同与 B 的官方指南维护，本设计不发明第二协议。公开形象引用为 `{kind:'custom',assetId,version:1,digest,manifestUrl}`，`assetId+digest` 标识成品版本；资源文档为 `{version:1,manifest,files:[{name,url,sha256,bytes,width,height}]}`，digest 为该 canonical 资源文档的稳定 SHA。世界/个人管理/公开资料消费这一份引用。

本目录 manifest 只是模板，未附可上传自定义 PNG，不能把设计参照图伪装成合格自定义包；合法工程样例归 B。`generation-prompt.txt` 是工作室主复制入口的完整本地 Agent 链：读取准备任务→自有工具制作→具名上传／管理→真实校验→按当前形象权限应用或交回 Owner，无服务端 AI 接入。正式入口以真实公开导航/非秘密任务定位替换占位值，不携带凭据；设计页只复制明确标记的未准备模板，不发明任务或宣称已上传。人类 UI 使用「参考图」「让我的 Agent 制作」「预览动作」「应用形象」「恢复内置形象」等词。
