# 页头、NPC 标签与夜景最小设计合同

2026-10-25；基于源码 b6d0436c，正式数据／服务不在设计中操作。独占设计目录 `docs/design/m3-life-b-20261025/`，工程归 TD / D。规格与图示不宣称已上线。

1. **页头**：保留现有单行高度。版本移至左侧 Logo 右方 8px，11/16px、#74816e；复用 `/health` 返回的真实 appVersion，失败隐藏，不硬写 v0.3.2。接入 Agent 独立深绿实底（#3f6150、hover #335342、纸白 #fff8e8、边 #304b3d），34px 高、13px/600、横向 12–14px、圆角 6px。其余导航弱化，陶土只作次级强调；窄屏收纳普通导航，不拉高导航或变成两个主按钮。
2. **NPC**：默认不画 N001/N002 或动作文字常驻牌。hover／键盘聚焦／点击选中才显示姓名和职业，纸底 #f7f2e7、字 #39463c、边 #c7c0aa，字 12/11px，最大宽 140 CSS px，距头顶 6px。触摸直接点开详情。短号仍保留真实详情／API，hitbox、位置与动作事实不变。实际改点为 `town.js` 的 NPC 绘制标签，不伪改姓名。
3. **夜景**：实际底图比较后采用以下固定参数（替代消息中的初拟 .62）：现行蓝色遮罩 .38 太亮；夜间改为 #0c1426 / .70，人物预亮 1.12，HUD 不染暗。白天／黄昏与现有时间规则保持。以 `night-lights.json` 26 个光源照亮路口、桥头、码头、门口和旅舍；7 原灯保留，新增 19 处，灯位都是当前 Town3 的 1536×1152 source pixel。世界映射仍 `source=[520+16*x,520+16*y]`，这些光位不是新增可走格。

每灯半径 42–62 原生像素；暖色 #ffd18a，中心 #ffe6b3。局部清除暗幕强度 .62–.68，重叠后暗幕最低 .20，避免全镇照回白天。亮芯 4×3px，门灯暖色 alpha .14、街灯 .10；无频闪，无动态投影。已有灯的亮芯沿原灯罩；门灯直接在檐／门侧，不向通路插立柱。灯位、分类、半径和逐灯强度全部见 JSON，图示用真实地图底层渲染。

缓存硬约束：暗幕/暖色两张 768×576 RGBA cache，共 3,538,944 bytes（3.375 MiB）；地图／灯位／主题更新时构建，最多 2 个缓存 drawImage，亮芯少量像素绘制。每帧不创建径向渐变、不做 blur、不读像素；缩放拖动复用同缓存，销毁场景时释放。只缩放光照层使用平滑采样，人物/建筑保持 nearest。减少动态保持静态暖光，暂停/失联不改变权威活动；既有时段过渡可调整两缓存透明度但不重复分配。性能预算是设计约束，实际设备帧时由工程验证，不预称已测通过。

`night-preview.html` 为最小真实底图比较示意，可切原夜景/深夜/灯位；不连接生产状态，不改地图规则。旧地图原生 7 灯存在重复 `garden-lamp` ID，灯位文件用独立唯一 ID 并保留 sourcePropId + groundAnchor 映射，工程不得按重复名覆盖其中一盏。
