# 钓鱼与渔人小铺实际素材交接

B 使用 WS03 catalog revision 1：只售木柄鱼竿 30 星币、鱼饵 2 星币；只收沙丁鱼 4、鲭鱼 8、海鲈 14，不售鱼。`fisher_shop` 复用 `e-stall`，店员离岗仍自助。两种钓点 4+3 席；每竿 60 秒、鱼饵 1、体力 2，1–5 竿；概率、预留、支出上限和空竿正常完成归 WS03。设计不另外裁定经济或接口。

## 实际交付

- `assets/items/` 五个 **32×32 透明 PNG** 与 160×32 atlas；assetId 固定 `life-item-basic_rod`、`life-item-bait`、`life-item-sardine`、`life-item-mackerel`、`life-item-sea_bass`。鱼饵采用纸包颗粒（1.0.1修正原杯装蚯蚓草稿），细长无纹银鱼、青背条纹鲭鱼、宽身斑点棘鳍海鲈具有不同轮廓。3px 最小留白，32/64/96/128 显示均 nearest，同一图在商店／背包／结果中复用。
- `assets/generated/` 是本轮内置 `image_gen` 实际生成的原始透明母图；`prompts/` 保存各最终提示。`image-export.json` 记录仅透明边界裁切、保持比例与 nearest 缩小，不借 HTML／SVG 假造物品画。客户端只加载小尺寸 PNG / atlas，不加载母图。
- `assets/fishing/` 32 条真实原生 base／tools／六发型的 CASTING / WAITING / REELING / CAUGHT 图层，以及店员 IDLE/WALK 的 base+spikeyhair。共 36 张，来源与逐张 SHA 在 `native-sources.json`，没有用文字规格代替动作素材。
- `animation-manifest.json` 固定 96×64 分帧、脚底 `[48,39]`、帧序／时长／镜像；原生素材右朝向，钓位全用整组左镜像。`npc-fishing-clerk` 用第五种原生 spikeyhair，职业区别通过店铺／鱼竿，默认不挂永久短号。
- `SPATIAL.md` 和空间 JSON 是已单独冻结的 B 地图包。接线读取真实新 map/rules/hash，不能仍以旧计数 1175 渲染新增席位。精确位置不复制到业务层手写维护。

## 动作与事实

开始的权威活动成立后，抛竿 15×80ms 只播一次；剩余进行期用等待帧 `[0,2,4,6]`、300ms 循环。页面迟到进入时按权威开始时间选择当前表现，不从头另算活动。收竿 13×80ms 及完成 10×80ms 由真实终态／回执驱动；有鱼获才在结果明细展示该鱼图片、数量和真实重量，空竿显示“这次没有钓到鱼”，不循环冒鱼、不因为动画结束补造成功。

同一次终态只播放一次；切 Agent、失去可见权限、场景卸载时清理。断线／未知状态停在静态等候姿态并说明正在确认，不使用本地时间猜结果。取消后的已消耗／已生效部分、预留释放、失败结果均以服务端为准。人物坐标仍由世界权威位置给出，station 分配不等于传送到席位。

减少动态时使用静帧和真实文字进度；不得靠闪烁强行提示咬钩。原生六种人形使用同一套 frame / feet；自定义非人形不得裁身、换成本素材人物或拼旧人腿：保留完整自有 idle，旁置鱼竿／线，使用真实状态文字；不宣称它有完整原生动作。只为屏内且实际活动的角色运行表现，纹理复用，禁止每帧解码／合成完整 atlas。无新轮询、定时外部推理或新增人物身份。

## 商店与背包

`index.html` 是用实际 PNG 与当前原生地图制作的可审阅预览。商店：原铺面及店员、售卖两项、收购三项、价格、库存／余额／可用性／提交状态由实际 reader 决定。店员离岗只改变人物在岗信息，不禁用自助交易。购买确认应同时列数量、单价、合计与实际余额；未确认或未知回执不预扣、不重复发单。

背包：同图标／名称／类型／实际数量，鱼获实际实例／重量、预留数量、来源与可执行用途。可用／预留使用可读文字；已消耗／已转出显示在历史记录，不算当前可用背包，不因保留条目而可重复使用。渔具正常使用不会消耗。出售只允许真实可用鱼获，预留不可卖，提交后未知先查询原回执。预览中的数量与状态切换明确为演示，不证明实物、交易或权限已通。

两条走读：①已有鱼竿和鱼饵→岸边四席任选合法空位→等待→按回执有鱼／空竿；②没钱／没工具→沿已有工作赚取→在原小铺买竿饵→前往栈台三席→出售实际鱼获。满员不挤入通路，改选另一钓区或稍后；断线/取消不重造物品。零余额退路依赖已交付 A 工作，不需要新用户补钱。
