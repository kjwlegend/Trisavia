# Trisavia 世界地图与玩家页面设计契约

2026-10-25。设计产物位于本目录；生产接线、版本与发布归TD。宏观地形为原创SVG，无外部地图或游戏素材。地域文案由WS02主笔，生产数据状态以真实实施为准。

## 先行固定：更新日志、建设看板与入口

本节已可独立交给 v0.1.2 作者，不等待宏观地图实现。

- 共用现有44px纸质顶栏、已批准Trisavia横标、36px按钮与特殊短切角/双线边框。颜色：纸`#F7F3E8`、正文`#263F36`、次文`#68746E`、细边`#D8D2C6`、浅绿`#DFE5D4`、主要操作陶土`#BE6346`。焦点2px `#577960`，offset3px；不能裁切焦点。
- `/releases` 标题「更新日志」，`/kanban` 标题「建设看板」。网页内容宽`min(1120px, 100% - 48px)`；顶栏下32px起。标题24/32px，副文14/22px，区段16/24px，卡片正文14/22px，元信息12/18px；页面标题与内容间24px，卡片内16px，平行卡间16px。标题行左侧「返回清昼小镇」，返回现世界入口，保持同源。整页正常纵向滚动，不把长内容硬塞固定高弹窗。
- 顶栏导航显示「世界地图／更新日志／建设看板」，当前页面用陶土字及2px下划线；不挤占底部既有5入口dock。现世界页将「世界地图」设为36px高的地图图标＋文字按钮，位于顶部品牌区之后；更新日志/建设看板可放现有更多菜单，窄于960px仍保留地图文字入口，其他两个收进更多。链接分别指`/releases`、`/kanban`。玩家页中的「世界地图」返回世界页再打开地图（由D/A共用约定参数或事件），不能在地图尚未交付时放无响应入口；v0.1.2可以先只给「返回清昼小镇」。
- 更新日志：单列阅读区最大800px；每个版本一块卡，顶部版本名16/24px＋日期12/18px＋真实发布状态。下方按「新增／优化／修复」分组，正文最多一条一个要点；若数据较多可展开旧版本。无截图占位、假发布时间、虚构更新计数。已发布/本地候选/未发布状态继承真实数据，不能把GitHub推送直接显示为UAT已发布。
- 建设看板：4列，视觉顺序「进行中／已完成／未来计划／投票中」，显示名映射作者现有真实状态，不为排版另建协议。≥1200px为4等列，列间16px；900–1199px为2×2，<900px为单列。不得横向拖拽滚动、缩小字体或假装支持拖拽变更状态。列标题16/24px＋实际条数12px，空列保留一句「这里暂时没有事项」。卡片16px内距、标题16/24px、两行摘要14/22px、状态或范围12/18px；长标题自然换行。
- 本批仅放「宏观世界地图」及「地区与场景扩展」相关真实事项；5张卡严格采用WS02固定稿：展开新城地图册、日落海·暮帆湾、逐鹿原·风禾驿、初晓洲·晨露湖畔、远岚山地·松雾谷；不另造卡。描述明确“首期仅清昼小镇可访问，其他地域为规划”，状态按真实实施，不提前放进完成列。没有投票服务则在「投票中」列显示「暂未开放投票」自然空态；不显示票数0、投票按钮或可点击计数，以免误认有真实投票。

## 世界层级与状态

世界 → 地区 → 城镇/场景/场所。西「日落海」、中「逐鹿原」、东「初晓洲」、北「远岚山地」；初晓洲为出生地区。只有清昼小镇开放，所在区域只能标“局部开放”，不能把初晓洲整体显示为可访问。未来目的地名称与文案为规划，不是既有服务。最终内容采用WS02固定提交 `9d4bd2e8df4359cb30c31bad489d488c90ae1c80` 的 `docs/workstreams/ws02-perception/product/world-story-20261025.md`。世界目标短句在弹窗标题下直接呈现；清昼小镇详情原文呈现其介绍及4个既有场所。

数据文件为`map-data.js`，交付清单见末节。宏观图只说明位置关系：没有真实比例尺、坐标网格、路线耗时、传送点或已建设比例。当前清昼小镇游戏地图、世界实例及服务能力完全沿用原数据。

## 弹窗与最小交互

- 点击世界地图入口打开居中弹窗，默认选中初晓洲、突出清昼小镇。1120×704px为桌面上限；宽`min(1120, viewport−48)`、高`min(704, viewport−64)`。顶栏72、面包屑42、底栏64；中间地图自适应、右详情292px，≤960px详情244px。正文14/22px，标题20/28px，元信息12/18px；不为装更多内容压缩正文。
- 地图展示自然海岸、山地、河流和地区虚线边界。可访问地点为绿实点，未开放为空心点；当前镇另有外圈＋文字标签，不只靠颜色。点地区名称查看地区简介及其目的地列表；点目的地查看详情与只读场所名，面包屑和返回地区入口保持。
- 「定位清昼小镇」只在宏观地图内重选、突出当前镇，不移动Agent。清昼小镇主按钮为「回到小镇地图」；关闭弹窗并回到/定位已载入小镇，不新增传送或切城。未来目的地按钮禁用，写「尚未开放」，没有href、请求或成功提示。
- Esc/关闭按钮关闭，焦点回入口；原生dialog加首尾Tab/Shift+Tab循环，焦点保持在弹窗。点击背景可关闭；详情不提交修改。≥811px桌面目标无面板滚动；过矮视口允许详情区兜底滚动，地图及底部动作始终可见。手机仅降级为地图＋详情纵排，不称本批完整手机体验通过。

## 数据边界

视觉catalog只含`region.id/name/state/pathId/anchor/destinations`与`destination.id/name/kind/state/anchor/summary/places`；anchor为0–100展示百分比，不是World坐标。`qingzhou-town`为纯UI目的地键，唯一映射现有`worldId: default`；`pixel-town-v2`及内部mapId保持原义。

回调：`onSelectRegion(id)`、`onSelectDestination(id)`只更新本地展示；`onLocateCurrentTown()`只选中宏观图上的当前镇；`onReturnToTown()`只关闭地图/返回既有世界视图；`onClose()`恢复焦点。生产如需世界相机定位，接既有安全定位能力，不调用移动命令。服务端开放状态未来接入时优先于静态文案，未知目的地一律禁用。

生产性能约束：地图与catalog按需加载，保持既有世界渲染和HUD行为；无需新轮询、持续动画循环、第三方渲染库、摄像机或地图坐标协议。打开/选择/关闭均本地展示操作。只在容器尺寸变化时适配地图。

本人已在1440×900、1024×768、811×854检查核心路径：地区/未来目的地→禁用入口、定位当前镇、当前镇介绍→回到小镇地图、关闭/Esc回入口、首尾Tab/Shift+Tab循环。所查桌面样本无内容横向溢出，详情无需滚动；1px框体伪元素外沿不计业务内容溢出。SVG可解析，JS语法通过，catalog的11个键唯一且仅清昼小镇开放。
