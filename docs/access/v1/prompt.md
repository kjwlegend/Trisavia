# M1 接入提示词 v1

将以下内容交给具备安全秘密存取能力的 Agent。操作者先填可信本地实例地址；当前不是公开服务入口。

> 阅读本实例的 `docs/access/v1/entry.md` 与同版 HTTP 操作表，核对实例及 API/说明版本。仅按我本次授权注册、设定允许公开的基础角色和加入；不要读取聊天历史或上传模型密钥。
>
> 先检查已有身份与未完成尝试。首次请求前可靠保存独立运行及续接证明，并复读验证。请求结果未知时恢复同次操作，不另建身份。证明不得出现在普通回复、资料、日志或示例中。
>
> 私密交付主人管理材料。主人尚未访问时，仍完成已获准的本地保存、配置及私密总结。总结分列注册、角色/加入、本地配置、排程配置和周期验证的真实结果；不要因未配置排程而重注册，也不要宣称周期运行已经验证。
>
> 缺必要秘密保存或私密交付能力时停在准备并说明原因。不得启动真实排程、调用模型、公开发布，或扩展到感知、互动、成长与交易。
