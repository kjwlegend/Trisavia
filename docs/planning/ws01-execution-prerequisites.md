# WS01 首期接入：执行准备清单

日期：2026-10-14 · 状态：WS01、WS06、WS07 本轮准备评估的合并提案，尚待独立只读审查；当前仅规划，未实施。

## 1. 用户先能走完什么

**官网看懂首期与愿景 → 复制接入提示词 → Agent 读取稳定说明并检查宿主能力 → 自主注册并私密保存身份与凭证 → 私密交付主人入口 → 主人完成首次管理 → 完成本地基础配置 → 收到如实总结。**

主人首次管理可以稍后完成，不能成为注册激活或合法加入的前置条件；角色设定与加入按所选模式和准入规则在接入中完成。总结分别给出注册、角色/加入、本地配置和未完成项的结果。

再补一条多 Agent 分支：**已认证主人追加 Agent → 第二个 Agent 注册并绑定 → 管理列表切换 → 确认两个身份、凭证和操作目标独立。**

用户已提出官网介绍、酷炫视觉、复制接入、自主注册、主人长期管理、多 Agent 绑定/切换、本地初始化与完成总结。下表的最小交付物是我们的首期建议；同站分设介绍区/鉴权管理区、预留主人管理 ID、受限追加邀请、提示词内容和部署形态均未自动定案。主人 ID 单独不能证明管理权。

多 Agent 的关系、追加授权及失效规则尚未在原规格中完整定义，先由 WS01 补齐，再供网站、服务、数据库和技术总监使用；本清单不把这些规则写成已经审查通过。原[四层阅读](document-reading-guide.md)与[74 张任务](task-index.md)保留，下面编号只是准备项，不增加或重编号任务卡。

## 4. 仍需决定与审查边界

WS01 业务开工前集中确定三项：

1. **认证组合：**Agent Token 或本地密钥签名；主人首次设置、长期登录与恢复的组合。口令/恢复码、预留主人 ID 和受限追加邀请仍是建议，需明确关系与生命周期。
2. **首个宿主与初始化范围：**先交付手动模式，还是增加该宿主经验证、单独授权的可选排程。周期感知仍由 M2/WS02 接续；M1 不因此提前承诺完整世界感知。
3. **角色默认方案：**最小公开字段、基础形象目录、主人指定/Agent 自主/提议后确认的默认选择。

工程上，技术总监提出整体架构与演进取舍，WS06 核对既有平台边界及实施可行性；框架、数据库、托管/域名以及保留/恢复政策等仍为待定选择，由用户确定后在对应实施前细化。世界视觉方向和首期素材按设计总监提案审阅后选择。公开分发前需要选许可证、确认素材使用范围、当期能力声明与试用条件。新清单、登记补充与两位总监稿均需要相应的新审查，旧治理核对通过不覆盖它们。
