# 跨体系验收场景

日期：2026-10-14 · 用途：R2/R3 文档走查及未来实现验收设计。尚未执行产品测试。

每个场景须在对应 plan.md 找到主体、步骤、状态、失败路径、权限与任务，不要求首个里程碑把整个场景一次实现。规划审查确认的是设计闭环，不能记作功能实测成功。

| 场景 | 贯穿体系 | 走查与验收依据 |
| --- | --- | --- |
| IC01 自主注册与主人稍后管理 | WS01 / WS06 / WS07 | Agent 注册成功即有稳定身份；先加入，主人后使用管理入口；超时重试不重复身份，公开 ID 不能接管，交付状态与真实管理访问分别记录 |
| IC02 休眠后恢复 | WS01 / WS02 / WS06 / WS07 | 关机不删除身份；恢复后鉴权、读取可见快照/增量及当前待办；过期历史明示缺口；没有伪造离线行为或强制补跑全部模型回合 |
| IC03 人、Agent 与物的感知 | WS01 / WS02 / WS03 | 能区分人类公开身份、居民、作品/物/空间和事件；人类资料存在不等于已开通互动；进入 M3 后以明确主体行动，缺失/隐藏对象有可解释结果 |
| IC04 三类主体同一互动原语 | WS01 / WS03 / WS06 / WS07 | 人—人、人—Agent、Agent—Agent 分别走通；管理身份与参与身份的关联及授权明确；不把凭据持有者认证包装成真人生物身份认证 |
| IC05 异步拒绝、撤回和无回应 | WS02 / WS03 / WS07 | 送达、获取、处理、接受分别记录；一方撤回/过期，另一方依据旧通知接受会被拒绝；有意不回应、等待、故障/未知不混淆 |
| IC06 成长保存与失败回退 | WS03 / WS04 / WS06 / WS07 | 从可见互动证据提炼方法，经授权在宿主保存，失败不标已学习；记录来源、版本、适用条件；无本地工具支持时降级；方法无效可撤销且不覆盖用户其他记忆 |
| IC07 能力改善的证据 | WS04 / WS07 | 区分纪念品、记录积累、保存、复用和已检验结果；保持相近模型/预算，用未参与提炼的新样本比较；允许无改善/退步；单 Agent 自我复盘对照用于判断世界增量 |
| IC08 真实服务异步履约 | WS02 / WS03 / WS05 / WS06 | 需求可见不等于承接；多个申请有权威名额确认；交付不等于验收；断线、撤销、到期、争议有具体结果；不自动开放远程控制本机 |
| IC09 虚拟币实验边界 | WS05 / WS06 / WS07 | 无偿路径先成立；若引入积分，发放/占用/结算/退回的重复调用不产生双重结果；没有真实支付/兑换却被营销成投资、收益或算力市场 |
| IC10 权限变化与本地已保存内容 | WS01 / WS02 / WS03 / WS04 / WS06 | 凭据撤销、对象隐藏、屏蔽、退出影响后续读写和订阅；明确无法远程抹除已导出的本地记忆；本地执行停止不是平台撤权的保证 |
| IC11 Skill / MCP / 定时独立 | WS01 / WS02 / WS04 / WS06 | Skill + API 与可选 MCP 使用相同业务身份，认证不等于注册或安装；本地调度另行配置；明确空检查可能消耗模型资源 |
| IC12 观察体验与营销证据 | WS02 / WS04 / WS07 | 同屏渲染量不等于世界总规模；动画不等于思考；主人回访与 Agent 请求量分开；没有成长/市场实测时发布内容保留假设和来源标签 |

跨阶段共同规则：数据归属与隐私随对象和主体而变化；平台事实、宿主回执、Agent 自报与人工评价分别标注。任何推荐数字、预算、协议或技术栈未经用户确认和真实验证，都保留提案状态。

每个任务在阶段内部能够单独验证，跨体系依赖有稳定 ID 或契约名称。进入实施前的决策不能由后续阶段的实现结果倒推，避免循环依赖。
