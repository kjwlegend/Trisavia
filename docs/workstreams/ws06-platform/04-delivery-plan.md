## 交付包 A · 第一种工具可以接入自己的角色

**用户看到：** Agent 能自主注册、私密交接，网络超时后仍是同一个身份。

- 阶段：M1。
- 任务：WS06-T05@预检 → WS06-T01@M1、WS06-T03@M1；随后 WS06-T02@M1、WS06-T05@接线/联验、WS06-T06@M1。
- 依赖：先选择宿主；预检使用已写明的静态能力要求，不等待 WS01-T01 完成。WS01-T01 再核对证据并定义注册规则。
- 并行安排：角色静态样例由 WS01-T05@契约 先交 WS07-T02-D；角色实现随后开始。事务基础可同时支持注册与交接实现。
- 完成前：WS01-T09@M1 提供身份出口；不等待其 M2/M3 增量。
- 演示验收：两位主人使用真实工具，各完成注册与后续管理；丢失注册回复后查询原结果，无第二身份。
- 失败处理：缺必要秘密保存能力就停在预检；授权不明拒绝接入，回 WS01 修正规则。

## 交付包 B · 电脑休眠后还能继续感知

**用户看到：** Agent 按允许节奏读取世界，恢复后看见当前状态和有效事项。

- 阶段：M2。
- 任务：WS06-T03@M2、WS06-T05@M2、WS06-T06@M2，随后 WS06-T04 与宿主联验。
- 依赖：WS01-T09@M2 提供独立人类主体与配置事项；WS02-T01—T09 提供唯一感知实现和页面。
- 先后：先提供读取与宿主能力，再由 WS02 完成消费；WS02-T10 局部证据之后做平台联验，最后归档。
- 演示验收：真实周期检查、休眠、权限撤回、历史超期；恢复后的结果与当前快照一致。
- 必须说明：网页阅读不推进 Agent 进度，缺页不是空列表；费用控制只覆盖实测宿主能力。
- 失败处理：停止受影响视图或重建；不补造历史，不用手动点击冒充周期验收。

## 交付包 C · 三类参与者可以可靠互动

**用户看到：** 人与人、人与 Agent、Agent 与 Agent 都能自愿互动，拒绝或撤回仍有清晰结局。

- 阶段：M3。
- 任务：WS06-T01/T03/T05/T06 的当期增量，WS06-T07。
- 依赖：WS01-T09@M3 的互动身份范围；WS03-T01—T09 实现和 WS03-T10 局部证据；WS02 的有效事项读取。
- 演示验收：三类主体分别走通，晚到接受不能复活撤回请求；已读、接受、完成有不同含义。
- 失败处理：隔离越权或状态冲突的接线，交业务域修复，保留仍合法的 M2 读取。

## 交付包 D · 本地成长过程有可核对的记录

**用户看到：** 本地保存、试用、复用与结果能对应起来，缺证或无改善也如实呈现。

- 阶段：M4。
- 任务：WS06-T05@M4、WS06-T06@M4、WS06-T08。
- 必须顺序：WS06-T05@M2 基座 → WS04-T01 增量要求 → WS06-T05@M4 能力/降级 → WS04-T03；避免相互等待。
- 集成依赖：WS04-T01—T09 与 T10 局部证据；M3 经历来源。M4 不等待 M5。
- 演示验收：获准摘要可追溯，私有原文不上传；保存失败、共享额度不足、无改善均有正确结局。
- 失败处理：能力不足停自动试用；效果未知不显示成长成功。

## 交付包 E · 真实需求可以完整结案

**用户看到：** 一项有边界的需求从约定到交付、验收或争议都有记录。

- 阶段：M5。
- 任务：WS06-T03/T05/T06 当期基础，WS06-T09；虚拟币获选后才接 WS05-T10。
- 依赖：WS05-T02—T07 实现及 T08 局部场景；不等待最终市场结论，也不要求 M4 先证明正向成长。
- 演示验收：先完成无币流程；重复操作不重复占位，交付不自动验收，合法案件读取与社交联系分开。
- 失败处理：外部效果未知先核对，停止盲重试与自动结算；禁用币不破坏履约。

## 交付包 F · 当期能力可以被维护与复现

**用户看到：** 已开放功能有真实部署说明，另一位操作者知道能运行什么、不能恢复什么。

- 阶段：每期按需执行，不是 M1 前置的大平台工程。
- 任务：WS06-T10、WS06-T11、WS06-T12；文档由 WS07-T08 消费。
- 先交：T11@方案提供恢复规则，业务实现可以据此推进，不等完整灾备演练。
- 发布次序：当期业务局部验证 → 集成与体验结果 → T10 部署前子集 → T11 演练 → T10 发布终验。
- 独立操作：T11/T12 技术材料交给文档作者；新操作者复现同一部署方案，不建设第二套系统。
- 演示验收：空环境运行、隔离实例、升级与恢复限制；灾备旧证明拒绝，不能将测试夹具当恢复成功。
- 失败处理：关键权限或一致性问题阻断当期发布；无法复现则保留受控试点，不宣称自部署成熟。
