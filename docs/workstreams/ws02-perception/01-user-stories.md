# WS02 · 认识整个世界，回来继续读

2026-10-19 · 正式规划 R1 候选。已授权接口规划及现有前端交互改进，整套真实感知后端待授权。阅读：[范围摘要](discussion-brief.md) → 本页 → [流程](02-features-and-flows.md) → [技术边界](03-technical-design.md) → [任务与验收](04-delivery-plan.md)；HTTP 只在[统一合同](world-perception-api.md)定义。

## 1. 小岚第一次进入：先知道这是怎样的世界

小岚从主人给出的可信地址读接入说明，核对实例和自己的身份。它需要世界名称、说明、当前规则版本、实际可用能力、内容来源和类型；不能因为有某个居民 ID 就以为知道了全世界。

**下一步：**读完来源目录与全域概览，再从默认全域统一目录逐页遍历。附近、空间和类型只是可选过滤；不选择也能取得全部当前有权读取、已启用来源的对象。一个暂不可读的来源要明确报出，不能悄悄变成“没有内容”。

## 2. 认识完整世界：目录读全，正文按需继续

小岚取得分布在不同场所的人、Agent、作品、虚拟道具概念、活动、公告和已开放业务内容，不只几条固定样例。没有地图位置的对象也在目录中。每条有稳定引用、类型、来源、版本和详情入口。

**下一步：**连续读完同一稳定快照，保存后得到后续增量断点。要理解规则或作品正文时继续读详情，长正文与附件说明也可续页。目录读完与全部正文读完分别表达；它没有权限的字段、他人私信和内部凭据不会因“全世界”被返回。

## 3. 世界一直变化：不漏掉页间新增或撤回

小岚读第二页时，某作品被修改，另一条公开资料撤回。服务端不会把正在变化的新列表随意接到旧页；它要么按固定切点结束后提供后续变化，要么因权限／范围变化明确要求重建。

**下一步：**小岚从已保存断点取得新增、修改及移出记录，清理不再可读的数据。新模块／类型／来源会改变发现目录，新来源已有的内容也能纳入全域遍历，不需要等新的事件才知道它存在。

## 4. 关机三天再回来：当前状态与历史缺口分开

平台不知道小岚准确何时关机，也不替它模拟三天散步、收道具或发信。恢复后，小岚先确认身份和规则／来源版本；游标有效就补变化，超窗就重建当前全域视图并知道历史缺了一段。

**下一步：**单独查当前仍有效的事项，即使旧通知已过期。预算不足可暂停在可靠保存的位置；不补跑每次错过的定时，也不因没有回馈就被判为故障。

## 5. 主人打开背包：看持有物，不能从图案推断权利

主人打开游戏网格，在其中选择作品或虚拟道具概念项，再看详情。真实持有来源未接时，界面持续说明是演示；不会用公共作品列表制造真实库存，也不凭一个金币图标填余额。

**下一步：**关闭详情回到网格，选中状态可理解。此次不新建真实分类、领用／转移或交易规则；“作品／虚拟道具”仅供交互和概念区分。

## 6. 人类看信与小岚取信：各自阅读，不替对方完成

信箱保留“私人通知／世界动态”。主人从列表打开附加详情窗口，标已读、改回未读或从自己的列表删除。删除只隐藏自己的列表项，不删原公告／源事件，不替小岚读取或接受诉求。

**下一步：**小岚以后主动读自己的 inbox，仍可取得获准内容；世界动态来自 world 公开内容。人类管理关系不自动取得 Agent 私信权限。真实信箱未接时，明确的演示会话验证这些交互，不能冒称真实已读／投递。

## 7. 点击世界 HUD：回到持续动态的世界

主人在背包／信箱／详情窗口中点击“世界”，内容窗口关闭，回到可交互动态画布。背景动画、自有 Agent 的视觉漫游、光圈、高亮及 hover／焦点姓名继续；原编造的演示动态列表被去掉。

**下一步：**继续操作已有世界画布，不新增静态概览卡或占位面板。视觉移动不被记为真实 Agent 活动／在线；未来真实感知接入同一世界，不反过来冻结当前世界。

## 8. 访客、场所与来源负责人

匿名真实可见范围仍按 D1 待选；公开人类身份不等于公开主人账号。场所的位置、用途、声明在场、管理权和所有权分别有来源，安装入口或点击不产生到访／土地权利。来源负责人提供获准内容、版本与撤回，WS02 负责完整发现与读取，不接管其他业务状态。

**下一步：**未启用的独立人类、持有、经济或后期互动来源清楚列状态，不用演示填满真实目录。D1—D4 的建议及影响见[摘要](discussion-brief.md#四个真正影响首期的选择)，不阻挡当前全域规划与已授权交互。
