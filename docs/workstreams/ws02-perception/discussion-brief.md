# WS02 · 完整世界感知与本轮交互范围

更新：2026-10-19。已授权完整接口规划及现有前端交互改进；整套真实感知后端尚未授权。本轮正文替代 10-15 的“先选局部”默认路径，历史审查保留在 [review](review.md)。唯一 HTTP／JSON 定义见[感知接口合同](world-perception-api.md)。

## 范围和可执行主流程

**默认遍历当前身份有权感知的全部世界内容。**无需先选附近、场所或标签；空间／类型／标签仅为可选过滤。全世界范围不包含他人的私信、邮箱、凭据和未公开关系，也不要求一次无限大响应。目录中的每个对象均可按需继续取得获准正文及附件说明，不能用固定演示或摘要列表冒充完整覆盖。

1. 从可信接入说明取得未来感知入口，核对实例、身份与协议，分页读完可披露的模块／内容类型／来源目录。
2. 读全域概览，知道哪些来源已启用、未启用或暂时失败；概览不是完整对象清单。
3. 用默认 `world/all` 开始固定来源集合及每源切点的初始快照，持续分页到明确结束；不是逐个猜已知 Agent ID。
4. 目录用稳定引用统一列出全部获准对象；按需分段读取详情。数据及进度可靠保存后，才把本地视图标成完整。
5. 从末页断点读取后续新增、修改、移出与撤回；新来源／类型通过目录版本变化发现，必要时重建以纳入已存在内容。
6. 本人背包 `inventory`、本人定向消息 `inbox` 独立遍历、独立进度；另查原业务当前事项。世界动态是 `world` 中的公告／活动／发生记录，不广播成每个人的私信。
7. 离线后先验权；checkpoint 有效则补读，只有它超窗才重建同通道当前视图并标历史缺口。仅续页过期按原操作重启：增量保留最后可靠 checkpoint 重读，快照／发现／当前事项各重启自身。触发和预算由 Agent 宿主决定，平台不唤醒它、不补做离线行动。

## 本轮前端业务

| 入口 | 本轮授权行为与事实边界 |
| --- | --- |
| 背包 | 游戏网格，支持选中物品看详情；作品／虚拟道具是概念，不新增真实分类体系、发放或交易。真实持有源未接时明确演示／未启用，不给假余额 |
| 信箱 | 保留“私人通知／世界动态”；列表进入附加详情窗口。人类可标已读／未读、从自己的列表删除；不删源事件、不替其他阅读者删除、不推进 Agent 进度。未接真实信箱时只验证清楚标识的演示交互，正常重开／刷新保持本读者状态，删除提供设计约定的撤销 |
| 世界 HUD | 回到持续动态、可交互的世界画布，关闭背包／信箱及附加详情；去掉原编造演示动态列表。保留画布动画、自有 Agent 视觉漫游／高亮／hover 或焦点显名；不新增静态概览卡、不冻结世界，也不把视觉运动当真实活动 |

## 四个真正影响首期的选择

| 未决项 | 当前建议／影响；不替用户定案 |
| --- | --- |
| D1 访客真实可见范围 | 全域遍历先按已认证主体的当前权限设计；匿名真实范围仍待选。全域不是全网公开，不阻塞认证后接口规划 |
| D2 首批消息来源 | 建议先接系统定向通知与世界公告；任意人机私信的生产仍属后期。接口可表达原创内容，不强制外部引用；前端本轮演示不等于选定真实生产源 |
| D3 背包／货币深度 | 本轮已定网格与作品／虚拟道具概念交互；真实持有来源、分类、币种／余额／转移未定，未接入时分别说明 |
| D4 场所／位置生产 | 建议管理员资料有来源／时间；动态世界画布已明确，真实移动、在场、土地权利仍未定。视觉动态不替代这些业务决定 |
