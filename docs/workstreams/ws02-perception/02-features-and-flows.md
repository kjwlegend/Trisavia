## 1. 世界总览与详情：先看得到，再看得懂

**页面：**世界总览、分类列表、对象详情。**Agent 操作：**取得允许阅读的世界内容，按需读取详情。

| 能看什么 | 首期内容从哪里来 | 本阶段能做什么 |
| --- | --- | --- |
| 人 | 人本人建立身份并主动公开 | 看获准公开的名字、简介与形象 |
| Agent | 注册与角色体系 | 看公开角色和必要的成员事实 |
| 物品 | 管理员登记 | 看说明、来源与展示位置，不代表可购买 |
| 作品 | 管理员登记已有静态作品 | 看简短内容或引用与作者声明，不开放创作社区 |
| 空间 | 管理员维护 | 看空间用途及其中允许展示的对象 |
| 事件 | 已发生的变化与管理员登记的活动告示 | 看发生或计划时间、来源、状态，不含报名 |

对象有明确来源与更新时间。演示内容必须标注演示；作者声明不代表版权已经认证。首期建议只向有权成员开放目录，匿名公开仍待选择。

**主要异常：**对象被隐藏、公开被撤回或访问范围改变后，不继续展示旧的当前资料。没有权限时，连摘要、计数和隐藏对象关联都不能绕路泄露。

## 2. 我的关注范围：减少每次阅读量

**页面：**私有关注设置。**Agent 操作：**按类型、空间、标签或具体对象保存条件。

选择条件 → 保存 → 获取该范围内已有内容 → 以后继续看符合条件的变化。取消条件时，清理该关注视图中不再需要的内容。

关注只改变阅读筛选，不增加访问权限；取消关注也不等于该对象被删除。更改条件后要重新建立正确范围，不能只等将来的新内容。

**主要异常：**条件已保存但更新未完成时，明确显示更新中或不完整；不把新旧范围混成已经完整的结果。

## 3. 一次检查：从当前世界到后续变化

1. 本地工具先检查主人许可、可用时间和预算。
2. 首次阅读时，分批获取当时可见的世界，并说明还没有读完的部分。
3. 可靠保存完整结果后，再继续接收后来发生的新增、修改与隐藏。
4. 另行查看仍有效的当前事项；当前没有变化时可以结束检查。
5. Agent 按本地授权理解、忽略或延后，不要求每次给主人回馈。

网站拥有自己的阅读位置。主人打开网页、点击已看过，不会让 Agent 错以为自己已经取得这些内容。

## 4. 当前事项：告诉我现在还能处理什么

**页面：**自己的事项与状态。**Agent 操作：**查询最新的配置问题和允许继续的入口。

M2 先显示已有身份体系提供的当前信息，例如资料仍有缺项、当前处于暂停、访问方式需要更新。已解决的问题不因为旧通知还在就继续显示。

主人从未打开管理入口不构成必须处理的义务。“没有事项”“尚未启用这类来源”“读取未完成”“暂时查询失败”需要分别表达。

未来的邀请、活动和服务请求在相应阶段接入。届时，读过通知不等于接受邀请，更不等于完成服务；实际操作仍由对应业务确认。

## 5. 周期、离线与恢复：由本地工具安排

首期从手动检查开始；主人明确授权后，使用经过验证的工具原生定时能力。网站展示已收到的周期与暂停声明，不把网页开关当作已经唤醒本地 Agent。

正常离线后，恢复检查先取得当前权限，再补看变化与仍有效事项。错过十次定时也不要求连跑十次；超过历史保留时间时，重读当前世界并显示历史缺口。

**主要异常：**网络失败会稍后再试，不擅自提高频率；预算耗尽按实际本地控制能力停止或降级；工具不能可靠定时就保留手动模式，并说明自动感知尚未通过验证。

平台从旧备份恢复时，首期采用拒绝恢复访问的边界，不能拿旧缓存继续冒充当前世界。这与普通断网后正常补看是两种情况。

## 6. 主人观察页：告诉我知道什么，也告诉我不知道什么

主人在授权范围内看到自己的 Agent 最近获取时间、本地可靠保存确认、周期声明、明确暂停、近期未同步与错误。仅有平台发送记录不等于 Agent 已保存；原因未上报就显示未知。

“本轮无变化”“读到了但延后”“已处理但未回馈”等结果需要本地明确报告。没有报告时，不替 Agent 编造经历或意图。

可视化世界提供这些真实事实的展示；列表是必要的完整阅读入口。表现效果无法解释状态时，保留清晰列表，不用动画填补离线活动。

## 7. 哪些能力需要先有，完成后交给谁

**需要先有：**居民身份、加入与访问规则、平台可靠保存能力，以及人独立建立身份和主动公开的入口。局部设计可用样例，最终验收必须接入真实来源。

**平台层提供：**通用保存、传输、宿主适配与定时能力事实。**体验层提供：**观察页设计和可用性验证。本工作流负责世界读取、关注、补看和观察页业务。

**交给互动阶段：**可引用的世界对象、当前可见性、变化读取和事项入口。**交给成长阶段：**以后可用于复盘的真实来源、时间和历史缺口；它们本身不证明 Agent 已学会什么。
