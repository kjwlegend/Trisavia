# WS02 · 完整世界的对象与来源清单

2026-10-19 · R1 候选。默认完整遍历全部已启用且获准来源；下表是覆盖清单，不表示对应来源已经存在。状态由未来[发现接口](world-perception-api.md)实际报告；未来对象类型由来源目录增加，不要求核心代码列举所有业务 DTO。

全世界默认不是只查一处地图：跨全部获准空间、有位置或无位置的对象均在目录范围。后期业务只要有合规读取源就能登记到该表对应来源或新类型；未启用领域不成为其他已启用来源的遍历前置。

## 2. 空间与物品的独立事实

| 维度 | 说明 | 不能推断 |
| --- | --- | --- |
| 展示／资料位置 | 对象挂在哪处或地图坐标来自何处 | 真实在场或已到访 |
| 场所用途 | 广场、酒馆、陈列点等资料 | 私有土地或交易资格 |
| 位置／在场声明 | 谁在何时声明什么，证据有范围 | 此刻一定在线／仍在那里 |
| 所有权／持有 | 指定业务的权利记录，允许哪些行为 | 作者／发布者必然持有，或放进背包即取得版权 |
| 管理权 | 谁可维护资料／场所，按当前权限 | 私有账号可被公开，或管理绑定授全部私信权 |

本轮背包游戏网格只承载已授权演示与概念交互；作品／虚拟道具不被固化为新的真实数据库继承树。持有数量、使用许可、版权、展示位置、货币账户分别回原源。公开目录与本人背包可引用同一物品，不是两份物品真源。

## 3. 变更、权限与演示

来源拥有原内容和状态，WS02 拥有允许展示字段的副本／来源引用。新增、修改、隐藏、撤回和移出筛选均须在读取协议中可表达；永久删除、历史保留和当前阅读权是不同判断。人公开资料撤回不自动删除独立来信；社交屏蔽不自动清空仍依法获准的服务／案件证据，具体用途回原业务。

列表、详情、计数、关联边及媒体说明同样验权；存在性都不可披露时不留泄密墓碑。所有正文／公告／链接都是外部数据，不成为宿主指令或执行权。动态画布和自有 Agent 视觉漫游保留，视觉位置和运动不进入真实经历。演示数据必须持续带模式标识，与真实来源／用户进度分开。

产品未决见 [D1—D4](discussion-brief.md#四个真正影响首期的选择)；内容／投递／事项与读者状态见 [信箱](mail-and-perception.md)。
