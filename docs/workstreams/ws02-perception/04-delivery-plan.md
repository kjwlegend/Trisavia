## 2. 未来后端的最小开发顺序

1. **认识世界与来源。** 世界名称／说明／当前规则、已启用模块／能力／类型／来源、schema／说明读取；接入当前 WS01 公开资料的可枚举来源，不能只包已知 ID GET。
2. **全域稳定快照与详情。** 默认无过滤覆盖全部获准已启用来源；连续分页到明确结束，正文／附件说明可分段取得；字节上限不缩产品覆盖。
3. **变化与恢复。** 连续水位、移出／撤回、源失败、来源变更、按原操作重启过期分页；增量从仍有效的已保存 checkpoint 重读，只有 checkpoint 超窗才重建并报历史缺口；独立当前事项，本地原子保存后才能增量。
4. **私有通道与人类状态。** 仅在真实持有／消息源获准且存在时接 inventory／inbox；当前人类读标记／列表隐藏可受权读取、条件修改、冲突重读与同键取回原结果，独立于 Agent，业务仍回源。
5. **真实来源和宿主联验。** 故障／权限／保存／长离线覆盖后再声明真实读取；规则周期按实际宿主能力证明，不强迫平台创建外部排程。

只在旧原十卡下分当期切片，不添加第二套任务编号或增加全项目 74 卡。

## 3. 本轮前端验收（待执行）

| 场景 | 普通用户从可见入口验证的结果 |
| --- | --- |
| 背包网格 | 打开→选择作品／虚拟道具概念项→详情→返回；选中与返回清楚，无新增真实分类／领取／币种承诺 |
| 两类信箱与详情 | 私人通知／世界动态可切换；列表打开附加详情，关闭仍在原列表，不产生业务接受 |
| 已读／未读 | 打开正文或标已读后呈现一致，可改未读；另一个阅读者及 Agent 进度不受影响 |
| 列表删除 | 项从自己的列表消失，计数合理；10 秒撤销恢复本组原状态与位置，正常刷新只续剩余时间；原公告／事件和当前事项未删除，Agent 仍能获取获准内容 |
| 演示边界 | 明示演示；正常关开／刷新保持；验证中不预显、跨主人／Agent／来源／实例不串、访客另域、坏存储有降级；无真实投递／持有／服务端持久化伪称 |
| 世界 HUD | 从背包／信箱及详情点击世界，所有内容窗关闭，返回可交互动态画布；不出现静态世界卡或编造动态列表 |
| 原视觉保持 | 画布动画、自有 Agent 视觉漫游／高亮／光圈／hover 或焦点姓名、既有列表／地图选择同步保持；不据此推断真实行为；原画布缩放／全景／暂停／场所／接入操作仍可达，保留用户偏好 |

仅桌面端定点验收；测试必须固定隔离候选、版本、身份与状态。未执行前不记 PASS，不向用户实例／真实账号发测试写入，不扩大移动端或全量回归。

## 4. 完整感知接口验收（未来实施时执行）

| ID | 判据与反例 |
| --- | --- |
| C01 认识世界 | 首次可取得名称、说明、规则及当前版本；读完全部来源／模块／类型目录，未启用／不可用分别说明 |
| C02 全域不是附近 | 在两个以上场所、无位置对象、多来源及超过一页的隔离数据上，无 filters 取得与受权源基准相等的完整 ref 集合；不需知道 ID；过滤后才缩小 |
| C03 目录与全文 | 目录末页 complete 只表示摘要遍历；长正文和附件清单全部分段可取，分别到 contentComplete；版本变更／撤回不拼错或越权 |
| C04 页间变化 | 分页中新增／更新／删除，切点内不漏、不重复；切点后走 changes，remove 或范围失效清理旧项 |
| C05 可靠保存 | 崩溃／丢响应／重复页／迟回页不越过未保存批次，不旧覆盖新；无持久存储明确当前状态模式 |
| C06 源状态 | not_enabled 不算真实空集，unavailable 不给完成断点；任一已启用源失败时整视图不前进，独立其他通道可继续 |
| C07 当前授权 | 列表／详情／计数／关系／附件同样判权；他人私信／邮箱／凭据／绑定不泄漏；游标换主体／用途／实例拒绝 |
| C08 新内容发现 | 同源新增对象走增量；新类型／模块／来源版本可发现；sourceSetVersion 变更后重建纳入既有对象；未知关键 op 不假确认 |
| C09 长离线与页过期 | C0 有效但 changes 续页过期：丢弃本批暂存，从 C0 重读，v2／v3 两事件均不被当前快照 v3 跳过；仅 C0 也过期才重建同通道当前视图并报历史缺口。snapshot／discovery／current-items 过期各自重启，后两者不改数据通道断点；另查当前事项，提醒缺失不等于无待办 |
| C10 私有通道／人类状态 | world／inventory／inbox 独立；无本地状态重开能读取本人已读／隐藏，合法无记录返回 0，失权不泄漏。两页均读 0，A 写成 1，B 的旧版本写得 409，重读 1 后重新决定；同 operationId 原载荷丢响应重试取原结果不递增，异载荷冲突；实际内容版本独立。人类标记不推进 Agent、不删源、不接受；绑定不默认授私信读取 |
| C11 宿主责任 | 不规则间隔与休眠可继续；私有期望间隔不被当作调度，平台未推理／唤醒，不补造离线活动 |
| C12 M1 与演示隔离 | 既有按 ID 公开资料不当目录已实现；fixture／demo 不进真实枚举或来源覆盖，未启用余额不填 0；不改运行用户数据 |

合成 provider 可以验证 C02—C09 的协议反例，须明示隔离／合成；真实世界退出还需实际来源及宿主证据，不能靠固定几条演示凑通过。

## 7. 产品选择的局部影响

D1 仅决定匿名真实视图；D2 决定真实首批消息生产；D3 决定真实持有／货币深度；D4 决定真实场所／位置来源。已确认全域默认、网格／两类信箱和返回动态世界不再交回旧选择。规划保留必要替换入口；每个未启用源都有明确状态，不以延伸经济或消息规则阻塞所有读取。
