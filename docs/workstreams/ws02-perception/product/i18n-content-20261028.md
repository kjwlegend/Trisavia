每个 locale namespace 目录只含 `zh-CN.json` 和 `en.json` 平面 ICU 字符串字典。来源索引分别置于 `apps/web/public/i18n/content-sources/world-content.json` 和 `life-content.json`，由接线／构建显式消费并纳入 hash，不送入 ICU 字符串编译；索引内 `resources.*.path` 相对于索引文件目录解析。调用为 `world-content:places.n-blue.v1.name` 等；稳定 ID 中既有的 `:`、`.`、`/` 原样保留，namespace 只按第一个冒号拆分。

来源索引共 150 组。每组固定原 `sourceId`／`sourceRef`／版本、字段到消息键映射、原始文件定位及 `sourceDigest`；NPC 另保留原人物故事摘要。摘要算法为 SHA-256：将 `fields` 指明的**当前原文字段值**按字段名排序，序列化为无空格、无 ASCII 转义、无末尾换行的 UTF-8 JSON 后计算。源文件整份 SHA 仅作归属核对，不能替代记录级验证。各 `version` 属其原内容／目录定义，不能与 World 指南号、活动状态版本或新语言包版本混用；地图无内容版本，明确为 null。

接线先取得原 reader 允许的对象，再按稳定 ID、字段摘要、原版本、selector、nativeStoryDigest／stateGuards 匹配；不是按中文显示文本全局替换。原文变化或版本／摘要不匹配时，回退当前获准原文并明确标记，不能继续静默展示旧英文；原对象失权、撤回或不可用时，不从公开字典恢复隐藏内容。具体失配提示由 WS07／接线作者沿共同 UI 约定实现。原机器摘要不修改，来源索引不产生新权限或动作。
