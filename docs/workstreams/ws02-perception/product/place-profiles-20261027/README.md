# 场所介绍唯一内容包 v1

供 TD／C／D 接入 0.10.2。唯一正文为 [profiles.v1.json](profiles.v1.json)，当前是内容交付，尚不表示工程或页面验收完成。

- 读取基线：本地 0.9.0，`4d29b9beae27a80bc7dfec2d1bde196e3ca22f6d`，地图 `pixel-town-v2`／layout `town-expansion-layout-v1`／版本 6。
- 覆盖 48 个既有目标：公共庭 1、建筑 31、漫步区域 6、Life 外场 9、园务牌 1。前 47 个来自当前场所菜单；园务牌按当前目录可用性显示。公告牌及动态 NPC 沿用原卡。
- 每项有独立 40–80 字介绍、当前名称、区域、既有图源及原图像素裁切、当前服务清单与 `ownerNpcId`；不增加场所、室内或业务功能。

| 字段 | 接线口径 |
| --- | --- |
| `profileId` | 本内容包的唯一索引；不是新增运行时 ID。 |
| `target.kind`＋`target.id` | 精确匹配现有地图／菜单命中对象；建筑的 `target.id` 即现有 building ID。 |
| `target.buildingId` | 建筑本体或 Life 外场所依附的现有建筑；同建筑的多个入口不能据此合并。 |
| `placeId`／`relatedPlaceIds` | 既有业务场所引用；没有对应业务场所的建筑、区域保留 `null`／空列表，不以建筑 ID 冒充 Life placeId。 |
| `name` | 保留各入口的实际名称，例如建筑“花径凉亭”对应外场“花园凉亭”，建筑“石岸旅舍”对应“石岸旅舍·西侧休憩廊”。 |
| `currentServices` | 0.9.0 已开放能力的说明索引；展示和操作条件仍取实时目录、权限、空位及状态，不据本字段生成新操作。 |
| `providerNpcIds` | 现有服务关联；不证明产权、NPC 此刻在场或全部服务须由其接待。 |
| `ownerNpcId` | 当前 48 项均为 `null`，省略整行所属；不显示“无主”。园丁之家与青禾的关系只在 `proposedOwnership` 留一条待确认提案。 |

NPC 姓名与故事只消费 M03 `npc-personas@1` 及 A/B 发布的同 ID 身份源；JSON 固定其路径与摘要，不复制第二份人物表。青禾是园务服务提供者，职业、建筑名称和停留位置均不作为产权证据。落实归属须另有 M03／TD 明确确认后更新版本。

图源均为现有设计素材：静态 `town-expanded.png` 为 **2048×1536 原图**，`sourceRect` 为 `[x,y,width,height]`，不是预览缩放坐标。31 栋建筑裁切包住完整建筑与少量落地周边；外场与区域使用同一真实地图的局部。园务牌使用其花圃已有 `care-watering.png` 第 0 帧 `[0,0,32,32]`，不把完成帧当实时状态。两图路径、尺寸、SHA-256 均在 JSON 的 `images` 中。

上述静态图只介绍地点，不承担实时居民、占位、照料结果或外场设施状态显示；不含实时人物／气泡／选中层。呈现沿既定 `contain`、像素缩放与左图右文合同：[场所介绍卡](../../../../design/place-profile-card-20261027.md)，固定设计提交 `9175bb0fd7751055e53441f9d1d094b5fab0f4a1`。
