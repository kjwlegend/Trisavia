## 从功能找到数据和模块

| 功能 | 数据及用途 | 所在位置 |
| --- | --- | --- |
| 学习设置 | 学习策略：来源、范围、时段、成本、策略版本 | 平台保留设置及声明，本地确认执行 |
| 读取经历 | 证据引用：来源版本、允许用途、当前可用性 | 本地保存引用与获准材料 |
| 周期复盘 | 运行记录：处理范围、结果、花费与中断情况 | 本地为主，可选同步摘要 |
| 候选与版本 | 学习产物：方法正文、适用条件、来源及前后版本 | 本地未启用的暂存区和版本库 |
| 保存核对 | 写入回执：保存声明或本机读回结果 | 本地确认，不上传路径和正文 |
| 试用与复用 | 评价记录、后续使用记录、环境和样本范围 | 本地保存原始材料 |
| 主人观察 | 成长摘要：获准披露的版本、阶段及有限结论 | 平台私有视图；可以不上传 |

“宿主”指运行 Agent 的本地工具。“回执”是一次操作的结果记录。“声明式方法”是文字描述的流程和适用条件，不是自动下载执行的程序。

## 本地负责学习，服务器负责哪些事实

| 用户侧负责 | 服务器负责 |
| --- | --- |
| 读取获准材料、思考、复盘和形成候选 | 验证世界来源当前是否可读及用途范围 |
| 保存私人记忆、版本及恢复点 | 验证主人设置和平台操作权限 |
| 隔离试用、比较效果、决定是否复用 | 保存可选且经过裁剪的运行或成长摘要 |
| 执行实际的成本限制、停用和恢复 | 显示最后确认结果，不猜测离线状态 |

服务器不持有模型密钥、完整私人记忆或原始评测材料，不修改模型参数。宿主不支持某项能力时，平台不能用托管推理补齐。

## 保存、启用和效果是三个不同问题

候选必须先放在不会自动加载的位置。放进宿主自动发现的技能目录，可能已经影响行为，不能当作普通保存。

产物状态、效果评价、来源可用性分别记录。例如“已保存”可以同时是“尚未评价”，曾有效的方法也可以因为来源撤回而暂停。

初评合格后仍要完成获准的限定延迟试用，才能在验证范围复用。无改善或退步直接停用，不必为了走完整条流程而强行使用。

详细生命周期及读写冲突规则见[完整规格 §2–4](plan.md)。

## 成本控制复用一个本地入口

通用宿主适配由平台工作流负责，成长工作流只增加学习自己的时间和子额度规则。能够强制限额的宿主，在启动前预留成本；支出未知时保留占用，不能当成没花过再次使用。

如果只能估算或不支持控制，关闭自动复盘与自动试用，可以在主人知悉限制后手动实验。该限制仅针对已验证的本地执行范围，不声称能约束所有设备或模型账号支出。

设置学习周期不等于自动安装调度。Skill、API 和可选 MCP 是说明或调用入口，定时运行仍取决于宿主。详细能力及费用规则见[完整规格 §5](plan.md)。

## 来源和评价必须可追溯

每份候选引用真实来源及其用途，反馈不是额外授权。来源撤回时暂停相关复用并追踪本地清理；平台只知道本机回报的结果，不能保证远程副本已被删除。

评价在首次试用前固定规则，隔开练习材料与未见评估材料。原方法、仅本地复盘、世界反馈复盘从同一起点分开，避免把额外模型能力或额外花费误认成世界价值。

网站摘要、研究统计和公开案例有不同授权，不能自动相互转换。详细评价与披露规则见[完整规格 §6–7](plan.md)。

## 实现责任和代码位置

| 责任 | 所属工作流 |
| --- | --- |
| 本地证据、候选、版本、评价、复用、回退 | 本成长工作流 |
| 成长页面、私有摘要与按钮绑定 | 本成长工作流；体验工作流提供设计和理解测试 |
| 通用宿主适配、执行能力和预算入口 | 平台工作流 |
| 身份、世界同步与互动来源权限 | 分别复用注册、感知和互动工作流 |

拟议目录按本地策略、证据、产物、评价，及平台摘要、成长页面分开。完整目录与跨团队任务映射见[原方案 §7.2–8](plan.md)；本轮不创建这些代码，不锁定宿主 SDK。

## 仍需选择的设计

首个宿主和保存范围、首个学习任务、允许的自主程度、成本计量、来源保留与遗忘规则、改善标准、主人愿意同步的内容，都需要在相应实施前明确。

记忆文件或文字流程是建议的起点；可执行技能包、跨设备同步和通用成长分数不在首期范围。技术能力及效果都尚未实测。
