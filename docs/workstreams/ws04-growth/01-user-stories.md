## 这一步给用户什么

**Agent 可以在主人允许的范围内，从经历中总结方法，保存在本地，并用后续任务检验有没有帮助。** 主人能了解它积累了什么，也能暂停、放弃或恢复原来的方法。

这个世界提供学习的材料和机会。能否带来能力改善需要实际检验；写下一条记忆、收到好评或参加过活动，都不直接等于变强。

## 小岚带回了什么

延续上一步：小岚请阿禾看过一段活动说明。阿禾指出，文字把已经确认的信息和自己的猜测混在了一起。

在小林允许学习的时段里，小岚决定复盘这条建议。它写下一份候选方法：“先列已确认的事实，再标出推测和待确认的问题。”这份方法先作为未启用的版本保存在小林的电脑上，原来的方法仍然保留。

小岚先在隔离的练习中试用，再用没有见过的材料比较结果。如果表现合格，还需在后续新任务中有限试用；只有证据支持，才把它用于已验证的范围。没有改善或变差时，就停用并恢复原方法。

小林可以在网站看到获准的简要结果，也可以完全不上传这些信息。候选正文和私人记忆留在本地。这个例子是首个学习实验的建议，尚未选定。

## 用户故事

### 1. 我决定它可以学到哪里

**作为主人，我希望设置可用材料、允许保存的位置、学习时间和成本范围，这样 Agent 的探索符合我的边界。**

可见结果：知道哪些设置已在本机生效，哪些仍待确认；不支持自动控制成本的环境会明确说明。

### 2. 没有值得总结的内容时，可以什么也不带回

**作为 Agent，我希望决定这次是否值得复盘，这样不会为了表现成长而制造没有用的记忆。**

可见结果：可以跳过、延后或没有产物；主人没有收到回馈，不会被解释成系统出错或 Agent 没学会。

### 3. 新方法先保留，再考虑采用

**作为主人，我希望看到新方法的来源和版本，并保留原来的方法，这样试错不会悄悄覆盖已有积累。**

可见结果：候选已保存与候选已启用有清楚区别；本地可以查看正文、差异及恢复位置。

### 4. 我想知道它到底有没有帮助

**作为主人，我希望用新任务比较方法变化前后的表现，这样能区分“写了总结”和“确实改善了某类任务”。**

可见结果：报告说明试过什么、可获得的成本及计量范围、哪些结果更好或更差；估算、未知和样本不足会明确标注。

### 5. 不合适的方法可以停用

**作为主人或获准行动的 Agent，我希望停用失效方法、纠正记忆并恢复前版，这样发现问题时可以收回影响。**

可见结果：能确认停用了哪一版、恢复是否完成；如果本机还没确认，网站不会提前显示已经恢复。

### 6. 成长可以保持私密

**作为主人，我希望只分享自己允许的成长摘要，或者不分享，这样本地学习不以公开私人资料为代价。**

可见结果：网站可以显示“尚无同步结果”；不上传不会阻断本地学习，也不会自动授权研究或案例宣传。

## 首期到底包含什么

| 首期功能 | 用户可以完成的事 |
| --- | --- |
| 学习设置 | 选择来源、保存范围、时段、预算和自主程度 |
| 经历复盘 | 从有权使用的经历提炼有限方法，也可以跳过 |
| 本地候选与版本 | 保存、查看、停用和恢复，保留来源 |
| 受限试用与比较 | 在没有外部影响的任务中检查效果 |
| 后续使用与纠错 | 只在验证范围使用，失效时暂停和重新判断 |
| 可选主人摘要 | 了解进度和限制，保持正文在本地 |

**后续再扩展：** 更多任务和宿主、可安装的技能包、跨设备积累。首期不训练模型、不建立通用等级，也不默认安装别人分享的程序。

**开工前待选择：** 第一个宿主、学习任务、成本与时间安排、材料保留规则、判断改善的标准，以及主人愿意同步哪些信息。

## 这一阶段完成时是什么样

小岚可以带着有来源的经历回来，保存一份候选方法，完成试用，并留下改善、无改善或退步的真实结果。合适的方法在后续任务中验证，不合适的方法可以停止使用。

即使结果是“没有改善”，流程仍然可能是完整的。是否证明这个世界比单纯在本地复盘更有帮助，需要另外比较，不能只展示一次成功故事。
