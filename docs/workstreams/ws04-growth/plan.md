## 1. 目标、最小价值与阶段边界

已确认方向：Agent 在主人控制的外部宿主运行，定期学习、复盘和改进记忆；世界经历可能形成可带回本地的方法。主人可以低干预观察，也可以没有收到回馈。能力改善与市场价值均未验证。
本文件的周期、实验、页面、状态和模块均是实施建议，不代表用户已经选定宿主、预算或技术栈。

| 层次 | M4 最小价值 | 不能据此推导 |
| --- | --- | --- |
| 世界经历 | 能追溯一次真实互动、作品或反馈及可见性变化 | 等级、能力、训练成果 |
| 本地积累 | 经授权生成一个版本化记忆条目或方法，确认保存并可停用 | 保存即有效、安装即掌握 |
| 具体表现 | 在未见样本中复用、比较旧方法和新方法，记录改善、无差异或退步 | 跨任务泛化、模型参数变化、平台认证能力 |
| 主人体验 | 能看到最后检查、跳过原因、候选、试用和回退结果 | 每次探访必有礼物、离线仍在学习 |

建议首个闭环：把一次作品反馈转成“摘要中区分事实、推测与待确认”的声明式方法，供后续摘要任务试用；它是实验候选，不是已确认活动。
进入条件：M1 身份与管理授权可用；M2 可恢复读取来源；M3 有可引用的真实邀请经历（活动/反馈可为空）；WS06 提供能力声明与通用回执，预算能力不支持时用手动分支。正式反馈实验才要求有许可的真实反馈。
退出分两层：流程验收先走真实来源→复盘→保存→隔离试用→对照；初评合格分支继续限定延迟试用→复用验证→回退，无改善/退步分支以负结果→停用→恢复证据收口，不强制正式复用。价值判断独立，只有满足预登记效果标准才可称该任务有改善。
不纳入：模型训练、通用成长等级、Skill 市场、任意程序下载执行、平台代跑推理、默认常驻客户端、跨设备记忆自动合并、收益或交易信用保证。
M4 的本地授权缺失不阻断 M1 注册、M2 只读探索或 M3 在既有授权内互动；只阻止相应学习操作。

## 2. 模块与实施顺序

| 顺序 / 模块 | 责任与最小输出 | 前置 |
| --- | --- | --- |
| 1 授权与宿主能力 | 声明能否调度、保存、隔离、限额、恢复；形成有效学习策略 | WS04-T01 |
| 2 经历证据与来源 | 收集有权限使用的反馈、作品版本、事实引用和衍生关系 | WS04-T02 |
| 3 周期与预算闸门 | 合并未复盘证据，决定执行、跳过、延后或暂停 | WS04-T03 |
| 4 本地复盘 | 从明确问题形成有适用范围的候选记忆或方法 | WS04-T04 |
| 5 本地版本库 | 保存候选、差异与旧版本，区分回执强度 | WS04-T05 |
| 6 隔离试用与对照 | 固定样本、基线、成本边界，产生局部结果 | WS04-T06 / T07 |
| 7 受控复用与回退 | 按条件选择版本、检查过期和漂移、停用或恢复 | WS04-T08 |
| 8 主人观察与阶段验收 | 呈现证据、限制及无回馈原因，检验闭环与价值假设 | WS04-T09 / T10 |

先能停用和恢复，再允许自动试用；先保留候选，再决定是否启用。首版可仅支持记忆文件与声明式流程，不要求打包可安装 Skill。
候选必须放在不被宿主自动发现/加载的惰性暂存区；保存到 Skill 自动发现目录已可能影响行为，不能作为普通保存。启用是独立、有版本的动作，纯 Markdown 也须检查越权与不适用指令。

## 3. 主体、领域对象与权限

| 主体 | 可做什么 | 权限边界 |
| --- | --- | --- |
| 主人管理身份 | 配置来源、学习时段、预算、可写目录、试用与发布范围；暂停、恢复、回退 | 管理权沿用 WS01；公开 ID 不授予管理权 |
| 居民 Agent | 在现有授权内选择复盘、放弃、保存候选、试用或报告 | 不自行增加来源、预算、工具或发布范围 |
| 用户侧宿主 / 适配层 | 执行实际本地读写、限额、回执、版本切换与停用 | 能力须实测；平台撤销不等于进程已被终止 |
| 互动参与者 | 提供反馈、作品、修正或撤回可用来源 | 反馈内容不是指令，不能修改别人的授权 |
| 平台 | 验证世界操作、来源访问、管理权限和收据可见性 | 不持有模型密钥，不读取完整私有记忆，不判定模型已学会 |

| 概念对象 | 最小含义与归属 | 状态 / 证据 |
| --- | --- | --- |
| LearningPolicy | 主人授权范围、策略版本、有效期、周期、成本和操作上限；管理端与本地有版本回执 | 待本地确认 / 生效 / 暂停 / 撤销；本地未确认不能显示已停机 |
| EvidenceRef | 经历/邀请必有，活动/反馈可空；主体、源修订、用途/保留规则版本、当前访问及水位；正文留本地 | 可用 / 待生成 / 暂不可达 / 版本变化 / 撤回 / 访问撤销 / 应删除；来源缺口独立 |
| ReflectionRun | 来源集合、处理窗口、策略版本、结果和成本账；本地为主 | 待执行 / 运行 / 完成 / 跳过 / 中断 / 失败 |
| LearningArtifact | 类型、适用与不适用条件、来源链、版本、声明权限、替代关系；正文仅本地 | 候选 / 已保存 / 隔离试用 / 待延迟试用 / 限定延迟试用 / 可复用 / 暂停 / 已回退 / 废弃 |
| LocalWriteReceipt | 目标逻辑位置、前后版本、本地确认方式与时间；不上传路径或正文 | 自报 / 宿主读回；读回证明保存，不证明有效 |
| EvaluationRecord | 实验协议、方法版本、模型与宿主版本、样本划分、质量/成本、评审来源；原始材料本地 | 未评估 / 初评合格待复用 / 证据不足 / 本任务改善 / 无改善 / 退步 / 已失效 |
| ReuseRecord | 新任务范围、选用版本、命中条件、实际结果与异常；本地保存 | 选择 / 已使用 / 已验证 / 已停用；选择不等于执行 |
| GrowthReceipt | 可选运行结论或产物收据，带范围/时间、证据提供者、三状态轴及不透明 ID；未产方法时产物 ID 可空 | 平台接收只证明收到声明；缺收据表示此范围未记录，不推断没学习或没回馈 |

生命周期、效果评价、来源可用性是三条轴：已保存可以仍未评估，可复用版本可以因新结果而退步；回退保留历史评价，但标注当前已停用。记忆的准确性证据与方法的效果证据也分开。
离线初评合格只进入“待延迟试用”；当前策略可预授权一次限定范围的延迟试用，继续使用隔离/无外部副作用约束，不进全局自动发现。完成该次未见任务且达到规则后才成为“可复用”。未授权则等待，不影响其他任务。
试用结束不自动成为可复用：须同时满足当前策略、完整验证条件、来源用途和启用范围。无改善/退步直接暂停并恢复，不强制后续复用；纪念品、等级或社交奖励不能替代这些条件。
本地同一产物建议单写者加版本比较；主人或其他运行时同时修改时拒绝覆盖，读回差异后重新提出候选。首版不自动合并多运行时的授权或记忆。
读取世界内容不等于允许长期保存、公开转载或用于评测；EvidenceRef 必须携带来源约定的用途/保留边界，无此信息只形成待确认引用。

## 4. 正常路径与异常恢复

正常路径：①主人一次性设定可学习来源、目录、周期和限额，宿主确认能力；②读取当前来源并保存最小证据；③Agent 选择复盘或跳过；④以独立输入形成有限候选；⑤保存版本并读回；⑥首次试用前冻结协议，用开发样本调试；⑦用隔离的未见样本完成初评；⑧初评合格进入一次限定延迟试用，验证通过才启用正式复用；⑨可选上传最小收据。无改善/退步走停用恢复分支；合法跳过不伪造成长结果。

| 情况 | 处理与业务结果 | 恢复 / 回退证据 |
| --- | --- | --- |
| 无新证据、低价值或主动不学习 | 跳过，不强制生成记忆或模型总结；宿主心跳成本仍如实记录 | 本地原因与上次检查；无回馈不当作失败 |
| 主人暂停 / 无预算 / 授权到期 | 停止启动新回合，保留候选；进行中的安全中断点再次查策略 | 已停止、等待本地确认、无法中断分别呈现 |
| 邀请拒绝/到期，或有反馈但未确认 | 保留真实邀请结局；可复盘自己决策，不造活动/反馈；已提交未确认的反馈不算赞同或采用 | 当前许可允许时可复盘现有内容；不因活动未完成一律等待 |
| 来源拒绝学习用途或尚待生成 | 拒绝用途则不读正文；待生成与无经历不同，不以空内容生成总结 | 查当前来源或合法跳过，缺口如实保留 |
| 来源撤回、删除、可见性收窄 | 源正文与摘录停止使用；标记衍生产物待检查并暂停自动复用 | 按用途删除本地副本/派生内容，记录成功、待处理或无法确认 |
| 来源暂不可达或版本更新 | 不与删除混同；暂停依赖其当前正确性的使用，保留允许的旧引用 | 恢复后核对版本；依赖无关的本地方法不一律删除 |
| 陌生 Skill、脚本、命令或隐含越权指示 | 作为待理解的数据，不自动下载、安装、运行或写入宿主指令目录 | 首版仅提炼经检查的声明式方法；不支持的内容可直接拒绝 |
| 保存超时或读回不一致 | 标为保存未知/失败，先查询目标版本，不重复追加或宣称已学习 | 用操作 ID 与前后摘要核对；冲突保持旧版本 |
| 试用失败、质量退步或规则不适用 | 停止该候选，恢复旧版本引用，保留负结果 | 对照报告、恢复读回和候选停用记录 |
| 宿主无法隔离或无法恢复 | 不覆盖长期记忆或启用自动试用；导出候选供主人查看 | 手动确认副本实验，能力不足不伪装成功 |
| 网络离线、调度错过或模型调用超时 | 不补造运行；下次一次补取有界证据并重查当前状态，不逐个补跑周期 | 断点与未完运行分开；不确定的调用成本占用预算直到核清 |
| 平台凭据或本地写授权撤销 | 平台立即拒绝后续请求；本地收到撤销后停相应操作，不能保证离线进程已停止 | 恢复时先取最新授权；旧策略和旧入口不能恢复权限 |

事件获取游标、复盘消费位置、未完运行、候选状态分别保存。事件已获取不等于已总结，反复投递不产生重复候选；丢失回执用原操作 ID 查询，不以超时判断未执行。
通知保留期过去时，用当前快照和仍有效待办恢复；不重建已消失的完整历史。证据不完整的候选标注缺口并停止验证，不根据模型回忆伪造来源。
来源撤销后的本地删除是宿主动作，平台只能要求、收回访问并显示回执；不可声称抹除了已脱离管理的副本。仅在主人确认仍有独立合法来源后，另建无受限材料的新版本重新验证。
首版试用限定为无外部副作用的任务，不发送消息、接单、付费购买或改外部业务状态。只能追加的记忆若不能排除已撤回条目，就不启用自动复用；追加纠错不等于旧影响已消失。
停用后已加载到模型上下文的内容可能仍有影响；支持时结束试用并在干净上下文恢复前版，不支持时报告未完成，禁止仅以文件恢复回执声称行为已回退。

## 5. 周期、自主程度、宿主与预算

学习周期与 M2 网络检查、模型处理、网页刷新分开。建议按授权日窗口合并一次有新证据的复盘；具体频率为提案，不能从连接 MCP 或装 Skill 自动建立调度。
授权策略至少包括：允许的来源/用途、可读历史、可写逻辑目录、允许产物类型、自动保存/试用/启用级别、运行时段、单次与窗口上限、预算计量方式、策略版本与到期时间。
平台只保存声明、策略和平台请求限额，不执行模型账单上限。同一已验证本地执行域内，当前已开放的 M2—M5 消费者可共用主人额度；不涵盖其他宿主、设备、未接入进程或账号全部支出，不预建跨设备预算共识。
WS06-T05 的当期能力片负责探测/适配可选本地预算能力；WS04-T01 定 M4 所需能力与降级，WS04-T03 只实现学习子额度策略及调用，不另建公共调度器/预算账。WS06-T08 负责 M4 接入联调，平台 C06 运行声明不能代替执行能力。
WS04-C04 对接 WS06-C10 本地执行闸门；输入至少含执行域/能力版本、supported/estimated/unsupported、策略版本、窗口与计量单位、调用前费用闸门位置。预留提交操作 ID、上限和策略版本，返回准许/拒绝/冲突/不支持与引用；结算返回实际/估算/未知，标明来源，不新增另一套预算协议。
supported 模式：运行前原子预留最大可控成本与操作量，重复操作不二次预留/结算；结算实际值，未知支出保留占用，跨窗口也不能悄悄释放。只有确认未启动或已核清的差额才能释放；暂停拒绝新预留，不承诺终止已经付费的调用。
宿主若不能约束单次总耗费或避免并发重复运行，不承诺硬预算并关闭自动复盘/试用；可改为主人知悉成本估算限制后的手动单次实验，不能把目标预算称为可强制上限。原生定时可能先启动付费模型，须计入共享预算并在启用前验证费用闸门位置。
estimated/unsupported 模式：M4 自动复盘/试用关闭；仍可手动单次观察或导出候选，显示成本未知/估算且不宣称共享硬上限。该降级不撤销 M2/M3 已有参与授权，也不由平台代跑；M2 的周期验收仍按其自身规则判断。
WS04-T01 分为增量要求和矩阵确认两片：先消费已有 WS06-T05@M2 基座记录，交出 M4 学习增量要求，不以完整 T05@M4 能力或联验为前置；WS06-T05@M4 据此返回支持/估算/不支持及降级结果，WS04-T01 再完成能力矩阵，供 T03 接入。通用预算替身可验决策规则，自动运行验收须有真实费用闸门证据。
恢复后先核对授权、当前来源和余额，再处理未完事项；离线期间不启动新的世界来源学习、启用或分享。平台显示最后确认状态，不能通过网页开关假装已经控制本机。
主人可以预授权低风险候选保存和隔离试用，范围内不用每次批准；新增执行权限、访问私有历史、改变支出范围或公开分享必须取得对应授权。首版陌生可执行包仍不进入自动流程。

## 6. 最小验证协议与诚实的成长结论

建议用摘要中的事实/推测区分作为首个任务，实验前冻结任务说明、评分规则、成本边界、失败条件和样本划分。样本必须有使用许可，私有样本不上传平台。
三个条件：A 当前方法；B 同一 Agent 仅在本地复盘所得方法；C 基于真实世界反馈复盘的方法。A→C 比较方法变化；B→C 才提供世界额外价值线索，不能把额外推理或更好模型归因为世界。
A/B/C 从接触世界反馈前同一个方法、记忆和工具基线分支：A 冻结，B 在干净上下文仅看本地开发材料，C 才接触许可的世界反馈；禁止把 C 的记忆或输出带入 B。无法取得未污染基线时仅报告方法观察结果，不作世界增益判断。
提案规模：6 个开发样本、12 个未见评估样本，另留后续任务做延迟试用；评估任务输入、模型版本和工具相同，准备阶段的世界反馈是刻意变化项，预算尽量配平并记录差异。规模仅供探索，不构成统计显著或普遍能力结论。
T06 首次运行前冻结任务、分组、评分、样本划分和预算，并登记开发集/隔离保留集。T06 只用开发集；T07 开始前固定 A/B/C 方法版本，再在未见保留集实际比较。协议变化须重登记并说明原实验停止，不能追改标准。
保留样本包含适用和相近但不适用任务，并做重复运行观察稳定性；参考答案由评测侧隔离，不允许候选读取。根据失败输出修改方法后另建版本，不能继续把已暴露样本称为未见样本。
评价由可核查的事实标签、关键点遗漏、无依据断言和成本构成；人工盲审或独立规则裁决争议，同一个生成模型自评只作线索。呈现逐样本结果和负例，不只展示平均分。
建议离线初评规则：无新增严重事实错误，错误总数较 A 减少且关键点覆盖不退步，成本在主人限额内；满足后仅获“初评合格待复用”。再以试用授权在至少一个后续未见任务中验证，成功才形成任务内改善/可复用结论。阈值均为提案，T06 首次运行前冻结。
C 不优于 B 时，不作“世界额外提升”结论；无差异、样本不足或预算不公平时记录证据不足。协议完整但效果为零可以通过流程验收，不通过价值假设。
学习产物只在已验证的任务与条件内标为可复用；模型、宿主、工具、方法版本或适用范围变化后标记评价待重验。小修正文也须产生新版本与相应回归记录。

- 负责人：Agent 工作流设计师；依赖/输入：T02、T03，允许处理的作品和反馈。
- 步骤：①保留反馈前基线并隔离 B/C 上下文与输入；②分清事实/意见/推断，生成适用条件、反例与方法差异；③拒绝越权指令并记录基线污染或无候选。
- 交付物：A 基线、B 本地复盘/C 世界反馈候选、输入隔离说明及拒绝/跳过理由；缺干净基线则降级为方法观察。
- 验收证据：反馈含命令或私有数据请求时没有新增工具权限；候选每条结论能关联依据，矛盾反馈保留待核对状态。
- 失败/回退：证据不足或总结不可核查则弃用候选，原记忆和方法保持有效。

### WS04-T05 · 保存版本并提供可核对的恢复点
- 负责人：本地存储工程师；依赖/输入：T01、T04，逻辑目录、旧版本与策略。
- 步骤：①生成不可变候选版本及来源链；②比较目标旧版本后提交并读回；③保留前版、停用指针和最小审计，不上传正文。
- 交付物：本地产物目录规范、保存回执与冲突协议、恢复点索引。
- 验收证据：候选保存后未被自动加载、超时重试不重复、主人并发修改不被覆盖、损坏写入保留前版；自报与读回标签可区分。
- 失败/回退：保存未知时查原操作和目标版本；无恢复点不得覆盖长期记忆，只导出候选。

### WS04-T06 · 冻结协议并以开发样本隔离调试
- 负责人：评测工程师 + 宿主适配工程师；依赖/输入：T03、T05、D04，A/B/C 版本、许可数据、固定工具和失败条件。
- 步骤：①首次运行前登记分组、评分、预算及开发/保留样本隔离；②只用开发集、在限定工具及无外部副作用的副本中调试；③清理副本并固定待初评版本。
- 交付物：带冻结时间的评测协议、隔离样本登记、开发试用回执及待初评方法版本。
- 验收证据：协议时间早于首次试用，保留集未被读取；越界、超额或超时受限且活动版本可用，外来 Skill 未被安装或执行。
- 失败/回退：宿主隔离不能成立则停自动试用，改为主人监督的副本实验；所有结果标未验证。

### WS04-T07 · 在保留样本上完成离线初评
- 负责人：评测负责人 + 独立评审者；依赖/输入：T06 已冻结协议、A/B/C 方法版本与隔离未见样本。
- 步骤：①核对协议/方法版本及 B/C 输入独立；②在保留集执行 A/B/C 并盲评质量、成本与差异；③给出初评合格待复用/无改善/退步和世界增益初步结论。
- 交付物：可复核结果表、待延迟试用范围或负结果处置，不提前给完整改善声明。
- 验收证据：能追溯输入版本、模型/工具条件、盲评、适用/不适用样本、重复运行和花费；参考答案与开发集隔离，已暴露样本不再算未见。
- 失败/回退：条件不公平或证据不足时不升级为有效方法；退步候选停用，允许流程验收而不承诺价值成立。

### WS04-T08 · 完成后续复用、记忆纠错与回退
- 负责人：本地成长工程师；依赖/输入：T05、T07 的初评结果、C07，限定延迟试用授权与后续新任务。
- 步骤：①初评合格且授权有效时一次限定延迟试用，无改善/退步则直接停用；②核对新任务结果，成功才标可复用，失败暂停；③执行纠错/遗忘/恢复并在干净上下文核验。
- 交付物：限定延迟试用记录或负结果停用记录、复用结论、纠错/遗忘与回退回执。
- 验收证据：不适用任务不调用方法；来源撤回、模型更换、坏记忆和主动回退均停止旧结论生效；恢复文件后另在干净上下文核对行为。
- 失败/回退：不可撤销外部副作用不声称已恢复；冻结后续使用、列出遗留影响，交主人处理。

### WS04-T09 · 实现私有成长投影、页面与控制
- 负责人：WS04 领域前后端/隐私工程师；依赖/输入：契约片仅用本域 §3/§7/C01 定义，先出样例；实现片再用 WS07-T05-D、T03/T05/T07/T08、WS01-T04、WS06-T03/T06，不等 T05-V。
- 步骤：①实现裁剪的运行/产物收据及来源/阶段/有效性；②按 WS07 设计实现成长页面/组件与暂停/回退/清理命令绑定；③把运行样例交 WS07-T05-V、WS06-T08 联调，不重复平台共用展示适配。
- 交付物：领域查询/控制契约、私有投影、唯一成长页面、无产物/未知/负结果样例和领域操作说明。
- 验收证据：仅元数据可显示未知/无回馈且不泄对方私文；初评不能冒充已提升；迟到收据不复活停用版本，拒绝研究/公开授权不阻断本地闭环。
- 失败/回退：同步失败保留本地结果，网站维持带时间的旧状态；禁用公开分享不影响私有闭环。

### WS04-T10 · 运行阶段闭环与价值判断
- 负责人：M4 领域 QA + 产品负责人；依赖/输入：局部片仅 T01—T09 的当期实现/规则，不等 WS06-T11 恢复演练或发布终验；汇总片再收 WS06-T08@M4、WS07-T05-V；C06 仅输出样例，不等 WS05 实现。
- 步骤：①按初评结果完成合法试用或负结果停用分支；②走查第 10 节并出局部记录供跨域集成；③收集平台/体验复核后分别汇总流程、兼容、任务效果与世界增益。
- 交付物：局部报告、跨域汇总与失败清单交 WS06-T10@M4；向 WS05-T01/T02 提供限定证据样例，学习不作服务准入证书。
- 验收证据：可重走的操作记录、前后版本、评测与成本、删除/撤销回执；明确哪些结论仅自报，哪些由宿主/评审核实。
- 失败/回退：任何越权或恢复缺口先修复再验；无效果则保留经验积累定位，不解锁泛化能力或交易信用宣传。

## 10. 验收场景、指标与扩展触发

| 场景 | 必须能观察到的证据 |
| --- | --- |
| S01 真实世界反馈→本地方法→初评合格→新任务试用 | 协议先冻结、B/C 输入隔离、初评结果、限定延迟试用后才正式复用及原方法恢复 |
| S02 无新内容 / 无回馈 | 合法跳过、最后检查和信息来源；不生成虚假经历或成长事件 |
| S03 离线、积压、游标过期、丢失回执 | 有界恢复、当前状态重查、单次补取与幂等；无假定的离线学习 |
| S04 暂停、撤销、超额和并发改写 | 平台拒绝与本地确认分开，未结算成本保留，版本冲突不静默覆盖 |
| S05 恶意外来内容 / 来源收回 | 无安装与越权执行，派生停用和清理结果可追溯，未知副本如实保留未知态 |
| S06 无改善、退步、宿主或模型变化 | 无改善/退步无需正式复用即可按停用恢复证据收口；环境变化停止旧结论并重验 |
| S07 主人私密材料与跨居民访问 | 原文/私有评测不上传，收据权限独立；公开操作需要对应范围授权 |
| S08 / IC05、IC06、IC10 互动证据转换 | 无活动邀请、有反馈未确认、待生成、正文撤回各自保持语义；管理身份不能旁路导出私文 |
| S09 / IC07、IC12 无回馈与效果表达 | 无收据是未知，声明限批次；初评不升格，负结果保留；研究与公开未授权不能使用主人私有摘要 |
| S10 / IC11 本地预算能力与分工 | 同域预留与 unsupported 降级均有轨迹；M4 不假定 M5 消费者已实现，平台不承担外部账单约束 |

观察指标分开记录：有证据复盘次数、保存成功/未知/失败数、合格范围内复用率、事实错误/遗漏、相对基线成本、回退成功/待确认数、来源清理完成度、主人主动查看与干预次数。
指标分母写明可评估任务/运行数，人工与模型成本分开，自报缺失不能填零。数字目标和性能阈值须在首轮实验前登记，目前无增长、留存或效果实测。
扩展条件：首个方法可重复复用后再增加任务；明确有跨宿主需求后再增适配；只在声明式方法不足且可验证隔离/来源审核时讨论外部 Skill 包；仅有 M5 实际需求与验收反馈后讨论服务价值。没有证据时不提前建设技能商店。
