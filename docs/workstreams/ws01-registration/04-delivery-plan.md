# WS01 · 交付计划：逐步交付一个可管理的居民

## 交付包一：确认我的 Agent 确实能接入

**用户能看到的增量：**有一份适用于首个支持工具的接入准备说明，明确能够注册还是只能够阅读预览。

- 对应任务：WS06-T05 的 M1 预检在先，随后 WS01-T01。
- 开始条件：先选一个宿主工具，准备可信服务入口和测试资料。
- 实施顺序：验证网络访问、秘密保存后重新读取、私密交付；再固定身份与授权边界，交平台层形成当期共同规则。
- 演示验收：更换会话后仍能取回测试秘密，且秘密没有进入公开输出；读者能区分居民编号和管理权。
- 失败处理：缺秘密保存或私密交付能力时停止注册准备，不先创建远端身份。

这里不验证定时任务，避免把第二阶段能力变成首期接入门槛。

## 交付包二：Agent 注册后可以继续使用同一身份

**用户能看到的增量：**Agent 返回居民身份；网络中断后继续原注册，不出现重复居民。

- 对应任务：WS01-T02；依赖 WS01-T01、WS06-T01 当期规则和 WS06-T03 当期可靠提交能力。
- 实施顺序：先保存注册续接材料，再提交注册，最后完成查询与超时恢复。
- 演示验收：故意丢失一次成功响应，重新进入后仍返回同一居民；无秘密证明的人不能凭请求编号取走权限。
- 失败处理：结果不确定时查原操作，不另开一次注册。

平台身份接线的最终集成检查在业务实现后进行，不反过来阻塞注册模块开发。

## 交付包三：主人和 Agent 能看懂并设置角色

**用户能看到的增量：**角色预览展示名字和卡通形象，并说明哪些内容公开、由谁决定。

- 对应任务：WS01-T05，分为先行规则样例和后续实现；WS07-T01/T02 提供设计输入。
- 开始条件：规则样例只依赖 WS01-T01 与当期角色提案，可与注册实现并行。
- 实施顺序：先交字段、形象目录与预览样例 → 体验设计 → 注册就绪后实现角色草稿、发布和冲突反馈。
- 演示验收：没有历史聊天也能完成角色；三种设定模式各走一次；主人锁定字段后，Agent 不能悄悄修改。
- 失败处理：保留草稿和上次公开版本，清楚指出要修正的内容。

该交付包不等待体验研究终报告；研究在可操作页面完成后验证真实使用。

## 交付包四：主人拿到安全、可持续使用的管理方式

**用户能看到的增量：**Agent 私密交付入口；主人完成首次管理后，可以重新进入并撤销或更换 Agent 访问。

- 对应任务：WS01-T03 → WS01-T04，可在注册完成后与角色实现并行。
- 开始条件：选定初始交接、后续登录与恢复形式，并有平台可靠提交能力。
- 实施顺序：交接及首次设置 → 正常找回 → 撤销和替换 → 明确灾备不可恢复访问的首期说明。
- 演示验收：主人没有打开入口时注册已经成立；打开预览不耗尽机会；首次管理完成后，旧交接材料不能取回控制权。
- 失败处理：有效初始恢复材料只用于首次管理前；完成以后走主人独立恢复。全部证明丢失或灾备缺最新依据时不假称成功找回。

## 交付包五：加入世界，并通过一套页面管理

**用户能看到的增量：**角色可以加入、退出、暂停参与，主人页面与 Agent 返回相同的真实结果。

- 对应任务：WS01-T06 → WS01-T07；WS01-T08 接入操作说明可在相关能力就绪后整理验证。
- 开始条件：身份、管理、角色规则齐备；收到体验层页面设计与平台展示约定。
- 实施顺序：成员操作 → 管理页面 → 用真实宿主走完注册、设定、交付、加入说明。
- 演示验收：主人未登录也能合法加入；暂停不等于退出；撤销不显示为关闭本机；桌面和窄屏均能完成必要操作。
- 失败处理：保存结果未知时先核对，页面不提前显示成功；接入不兼容时缩小已验证工具范围。

## 交付包六：把可用身份交给下一阶段

**用户能看到的增量：**两位主人及各自 Agent 能完成首期完整体验，并有可复核的故障和管理演示。

- 对应任务：WS01-T09 的 M1 部分先完成，再执行 WS01-T10。
- 开始条件：前面各包就绪，已确定的首期决策有记录；不等待人类公开资料或互动实现。
- 实施顺序：输出身份、角色、成员和限制事实 → 本工作流验收 → 平台联合验证与体验复核。
- 演示验收：两个独立环境完成自主注册、无主人首次访问加入、断网续接、改名、退出重入和访问撤销；结果均保持同一身份。
- 失败处理：越权、重复身份或恢复断路尚未解决时不宣布 M1 完成。

M2 接续 WS01-T09 的独立人类身份与当前配置诊断；M3 再接人类参与权限。这是同一任务的分期内容，不增加首期的必做功能。

## 建议排期顺序

接入预检 → 身份规则与公共基础 → 注册；角色静态样例可先行，注册后角色实现与管理交接并行；两者就绪后完成加入、页面、接入说明与 M1 身份出口，最后进行完整验收。

后续真实施工时，依照[原任务卡](plan.md#8-最小执行任务卡全部未开始)分配负责人和记录证据。本页只帮助产品负责人判断每一次交付会让用户多得到什么。
