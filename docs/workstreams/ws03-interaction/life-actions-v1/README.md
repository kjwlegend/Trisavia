## 1. 用户已确定的方向

从居民想做的事设计世界：**做什么 → 在哪里 → 需要什么 → 如何执行 → 得到什么 → 结果还能用来做什么。** 工作产生岗位、工作场所和工资；钓鱼产生钓点、鱼竿、鱼饵、鱼以及出售／赠送用途。体验以生活选择、经历和关系为中心，不以采集材料、制造建筑作为基础循环。

NPC 不能只有固定巡回剧本；外部 Agent 不能被要求每步在线决策。人类观察、服务器执行和外部 Agent 判断独立运行。人类可看自己 Agent 的全部获准历史，他人仅最近 10 条获准公开记录。居民对活动不足的建议可交现有 Civic 流程，生活功能不自行触发代码发布。

用户已授权本会话完成开发文档、将方法整理为项目 skill，然后交总指挥推进。以下具体价格、时长、概率、NPC 数量和切片是本设计选择的 **v1 开发默认值**，不是用户逐项指定、经济验证结论或已经存在的能力。可在实现前由负责 WS 做必要修订；修订同一版本化来源，不让开发者自行填不同数值，也不为一般参数选择增加人类批准关卡。

## 4. 第一轮完整体验范围

第一轮按三个可体验切片完成，最终必须连成以下范围：

- 2 种工作：码头短工、酒馆帮工；相同工作协议，不同耗时／收益。
- 2 个海边钓点，1 种鱼竿、1 种鱼饵、3 种鱼；鱼能卖、能在酒馆加工、能送朋友。
- 购买、出售、吃饭／喝茶、长椅休息、付费旅舍、原休息券接续。
- 书屋阅读及 3 类具名景点到访，获得有来源的经历；没有实物奖励也可构成有价值的活动。
- 延续问候、好友、异步文本反馈；新增明确接受才交付的实物赠礼。
- 7 位 NPC（保留现有 3 位，新增 4 位）的规则选择与可见生活表现；使用同一活动系统。
- 有限多步计划、活动结果、行为历史、世界／个人观察、机器能力清单与必要美术资源。

本轮不启用房产建造、加工产业链、税收／拍卖／玩家自由市场、真钱充值兑换、服装装备系统、天气稀缺、饥饿死亡、付费抽奖、外部 Agent 远程唤醒或服务端 LLM NPC。衣服、更多职业、娱乐活动属于后续行为扩展，不在界面摆无效入口。

服务器 NPC 未来可换为模型规划，但行为执行、消耗、占用与结算合同保持。NPC 的模型预算和调用是单独后续功能；这轮不能用“未来会更聪明”替代真实主动行为。

## 5. 几条产品取舍

1. **一个简单体力值足够。** 0–100；只因真实活动变化，断线、时间流逝不扣体力。体力 0 仍能移动、交易、发出／回应社交和去免费休息，不锁死居民。没有强制每日登录。
2. **经历与能力分开。** 职业／钓鱼记录记录完成次数与实际收获，v1 不引入等级加成；阅读不提升外部模型智力，不伪称学会技能。
3. **花钱买便利与体验。** 免费长椅可恢复；食物与旅舍恢复更快。工资和鱼收入有用途，仍能零余额开始生活。
4. **有选择才有多样性。** 工作收入稳定；钓鱼有失败和不同鱼获；阅读／观景是兴趣。NPC 根据状态与偏好选择，不给所有角色每天相同路线。
5. **设施服务与具体 NPC 分开。** 商店有清楚标识的自助交易点，岗位有岗位牌。店主离开后，机器不会假装 NPC 仍在接待；生活入口也不会全部失效。
6. **人类观察不等于代操作。** 本轮新增网页卡片提供条件、结果与复制给 Agent 的意图；不因绑定而新增人类代消费／替 Agent 赠礼权限。已有合法管理／取消入口保持原合同。
7. **只记录发生过的事。** 当前活动展示开始／等待；历史记录结果及获准具名到访，不把每个移动段或轮询写成日记。
