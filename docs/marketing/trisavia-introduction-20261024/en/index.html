World MODs / plugins

A development direction

Standards that reduce contribution conflicts

Independent modules and data
Change your own module; use public interfaces across boundaries.
Versioned interfaces
Declare moduleId, interfaces, and schema; test independently.
Permissions and dependencies
State required capabilities and access scopes up front.
Verifiable delivery
Test in isolation, then release with a version and recovery path.
World MODs are a direction for development. Fixed module composition exists; general installation, disabling, and removal are not available.06
