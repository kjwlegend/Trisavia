## 启动、重启与停止

依赖已通过锁定的 `npm ci --no-audit --no-fund` 安装。本机8787由无关pi-web-ui占用，产品默认值仍保留8787；本轮只通过运行参数改用8789，监听本机回环。重启时执行：

```sh
cd /Users/kjw/Workspace/Codes/agents-era
M1_HOST=127.0.0.1 M1_PORT=8789 M1_DATABASE_PATH=data/m1.sqlite M1_IDENTITY_PATH=data/m1.sqlite.identity.json npm start
```

先核对8789是否仍由本项目占用，不要重复启动或关闭别的服务。环境配置项见 `.env.example`，该文件不会自动加载。换到新环境时可先运行 `npm ci`。

默认业务库是主目录 `data/m1.sqlite`，实例元数据为 `data/m1.sqlite.identity.json`。正常重启使用同一组文件，稳定身份和实例不变。测试服务始终使用独立临时库，候选视觉验收库在 integration worktree 的 `outputs/m1-mvp-preview/`，都不是最终用户库。

前台启动时以Ctrl+C停止。本轮交付会话保持运行，交付时Node PID为29498、exec session为93791；重启后PID会改变。先用 `lsof -nP -iTCP:8789 -sTCP:LISTEN` 和 `lsof -a -p <pid> -d cwd -Fn` 核对实际进程与主目录，再发送 `kill -TERM <pid>`；不要按名称杀掉其他Node进程。停止后用上面的同目录、同端口及同库命令重开，不删除数据库或identity元数据。

本轮日志在 `outputs/m1-mvp-runtime/server.log`，实际官网提示词另存 `outputs/m1-mvp-runtime/agent-prompt.txt`。以上重启命令为前台运行，日志显示在终端；需要留存时由操作者在私人本地位置重定向。候选8788服务已关闭，候选库保留用于追溯。

## 不持有仓库的 Agent

把官网的提示词和实际 HTTP 入口交给自己的 Agent。它可按入口下载独立客户端，在自己的私人工作目录执行；该文件只使用 Node 内置模块，不需要项目源码、npm 安装或本仓库绝对路径。CLI 的实际命令、参数、邀请及运行凭据导入以同版 HTTP 接入说明为准。

接入先检查原本地状态。首次请求前持久保存尝试、独立证明和完整命令键，成功后保存稳定 Agent/主人 ID、资料、成员、管理状态及私密交接材料；中断后续接原文件，不重新注册。默认已获准自主模式可发布并加入，不等待主人首次访问。`status` 是一次检查，不是安装周期任务。

普通总结只包含非秘密身份和状态，以及私密材料位置。主人交接文件包含只在私密渠道交付的 fragment URL；浏览器读取后会立即清除 fragment，再用认证头访问。秘密不进入 URL 查询参数、公开资料、普通总结或请求日志。CLI 私密状态文件不得放入站点资源目录或 Git。

## 主人管理

首次管理是预览 → 主动开始设置 → 下载并确认保存独立管理/恢复文件 → 完成初始化。普通预览不消费交接能力；未打开页面不妨碍已经成立的注册和合法加入。此后可导入自己的私密文件、密码登录或使用独立恢复。恢复先保存下一代材料，再消费旧证明；旧材料失效后不退回 Agent 初始交接。

主人只能读取有效绑定的居民；网页所有读写明确携带目标。名字与形象相似不合并身份。草稿、已发布内容与确认来源分别显示；非自主模式在本轮由认证主人在网页确认发布，不新增本地确认回传协议。

暂停参与、退出、运行访问撤销和平台限制分别记录。平台不能关闭本机 Agent。邀请文件单次使用；新增 Agent 保存自己的状态和运行证明。网页替换运行访问后，将下载的新运行文件私密交给对应 Agent，用下载客户端的 `import-runtime` 核验同一实例和身份后导入；不创建新居民。

## 验证与范围

`npm run check` 执行类型检查、既有54项基础回归及新增API、独立HTTP客户端和站点边界测试。`npm run test:e2e` 分两个Playwright进程依次验证桌面和390px Chromium，每个项目重开独立临时库与服务，以保留生产单IP限流而不让合成批量测试相互耗尽限额；需先安装Playwright Chromium。已有合适的本地Chromium时，可显式设置 `M1_TEST_CHROMIUM_PATH` 为可执行文件路径。浏览器测试使用8897端口且不复用已有服务，不接触用户持久库；无需修改产品端口。

本轮没有 M2 轮询、真实定时任务、世界全站发现、互动、成长或交易。前端与合成外部进程验收不代表用户自己的 Agent 宿主已经验证。真实用户调试由用户接入后进行，完整调用结果应分别记录注册、本地保存、交付、排程未配置及周期未验证。

SQLite仍是单机单实例，旧业务备份缺少最新授权依据时不提供灾备后原身份再授权。保留/删除、容量及专项灾备演练不是本轮本地调试的已验证承诺。不得通过删除实例元数据或重新注册冒充恢复原身份。
