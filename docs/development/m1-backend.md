# M1 后端候选的工程默认

状态：本地实施候选，尚未经专门独立代码审查；不代表M1全量完成或允许公开部署。前端、视觉、模型调用、真实用户与真实排程不在本批范围。

工程默认采用Node 24、TypeScript、Fastify与内置SQLite，单机单实例。版本以package-lock为准。这是减少本地依赖的可逆选择，不冻结未来数据库或产品方案。启动只绑定回环地址，持久库在忽略目录data内；测试默认使用隔离内存库。

认证默认采用独立的不透明Token，不实现数字签名或MCP。注册客户端预先保存运行与续接材料，服务端只保存校验材料；首次主人与新Agent邀请分别限制用途。主人长期口令与恢复/会话分离。主人编号前移、单次邀请、期限及角色默认均为本批可调整工程选择，尚非永久产品承诺。

工作包分别维护存储、API和接入/验收，候选在独立integration worktree组合。接口只覆盖M1；未来业务只有方向，不预建实现。

## 运行和验证

使用Node 24执行 `npm ci`，再执行 `npm run check`。本地运行入口为 `npm start`，默认 `http://127.0.0.1:8787`；配置项见根 `.env.example`，示例文件不会自动加载。具体已实现接口及限制由接入材料和测试证据给出，不以本页列名代替实现。

实例ID与恢复代次存于独立的本地identity元数据文件，首次建立后保持稳定；损坏或与环境冲突时拒绝静默重建。数据库和元数据不是同一文件。身份元数据不含模型key或用户Token，仍应私密保存；不将它与业务库一起回滚。恢复旧库时，维护者必须明确切换到新的恢复代次，旧凭据不能重新取得访问。本批不提供灾备后原身份再授权，不声称能自动识别任意文件回滚。不要删除元数据后靠重新注册找回原身份。

端口、数据库路径和实例配置是本地开发设置，不是宿主调度或模型配置。运行日志不记录请求正文、认证头或私密管理链接。

每包保留提交和实际测试结果。候选送审固定base/target；尚未通过独立代码审查前，不合入main或公开发布。
