# M1 非视觉集成验收矩阵

本文件覆盖后端 HTTP 黑盒及合成客户端，关联原 WS01-T08/T10，不增加原任务卡。测试输入固定为模拟 O1/O2 与 A1/A2/B1；A1/A2 属 O1，B1 属 O2。没有真实用户、模型、排程或前端验证。

| 场景 | 核对点 |
| --- | --- |
| INT-01 | 两位主人独立首注册；未首次管理仍可设定、合法加入与本地总结 |
| INT-02 | 注册提交成功丢响应，同次查询及并发重试保持唯一身份 |
| INT-03 | 同尝试换载荷冲突；公开尝试号/居民 ID/主人 ID 不授权 |
| INT-04 | 交接普通预览不消费；过期、换发及旧代次重放清楚拒绝 |
| INT-05 | 受限设置不具完整管理权；先存长期证明再完成，丢响应不退回初始材料 |
| INT-06 | 长期登录与实际支持的正常恢复；全丢失及灾备限制明示 |
| INT-07 | 主人邀请新增 A2，邀请消费、身份与有效绑定一致提交 |
| INT-08 | 邀请过期/撤销/争用；同次丢响应续接不创建第四身份 |
| INT-09 | 主人列表与显式目标切换；迟到响应保持原目标归属 |
| INT-10 | O2、Agent 与公开 ID 均不能取得 O1 管理权限或私有关系 |
| INT-11 | A1/A2 运行凭据独立；定向撤销不影响另一个 Agent |
| INT-12 | 首次管理后旧交接/续接证明失效；撤销前后提交顺序正确 |
| INT-13 | 基础角色目录、三种设定模式及资料校验；非自主模式需主人发布，角色名不授予权限 |
| INT-14 | 主人锁字段及资料版本冲突不静默覆盖，失败保留已发布状态 |
| INT-15 | member、主人暂停、平台限制、凭据状态分轴；退出重入身份不变 |

运行命令、实际结果及未覆盖项记录于 [evidence.md](evidence.md)。API 路径与字段只消费 [同版操作表](../../access/v1/http-api.md) 和实际服务，不能在测试中另建业务规则。

证据仅记录场景、版本、状态、目标及非秘密操作号。秘密留局部变量或测试私密存储，不写断言消息、普通日志或快照。测试异常只报告安全的分类及状态；不得把完整请求头或返回正文串入失败输出。

API 集成、真实宿主秘密复读、私密交付、配置、排程配置、周期验证分别结论。当前后四项不能由本套合成测试推断通过。独立代码审查另行执行，作者测试不替代审查。
