# M1 MVP 公开入口浏览器验收

本页仅记录 `tests/e2e/entry.spec.ts` 作者范围，主人全生命周期由独立的 `owner.spec.ts` 作者交付。浏览器使用已有 Chromium 153，显式设置 `M1_TEST_CHROMIUM_PATH`；不把本机绝对浏览器路径写成产品默认。

命令：`npx playwright test tests/e2e/entry.spec.ts`（设置上述本机测试浏览器环境变量）。实际 desktop 1440×1000 与 mobile 390×844 共 **6/6 通过**，无跳过；两个项目均另外 resize 到 320×800 检查减少动画与布局。`npm run typecheck`、`git diff --check` 通过。

| 浏览器事实 | 验证结果 |
| --- | --- |
| 匿名首页 | 同源提示词/Markdown/下载入口可用；匿名庭院不发全站居民查询；三场所可通过语义按钮/键盘说明用途，后期发现如实未启用 |
| 390 与 320 | 无页面横向溢出；两个顶部导航链接实际 bounding box 的宽/高均至少 44px；减少动画 media query 生效，主要入口与主人认证入口保持可用 |
| 用户没有仓库 | 实际点击下载单文件客户端，在无仓库的临时目录用 Node 外部进程注册/发布/加入；随后浏览器打开明确 ID 的公开页 |
| 公开隐私 | 匿名响应为明确允许字段，无主人 ID、草稿、字段政策或证明；页面不显示私有材料；另存未发布草稿不改变公开名，退出后统一不可见 |
| 浏览器错误 | 持续监听 pageerror、console error、失败请求/HTTP 响应与秘密 query；正向路径没有意外问题，退出后的预期公开 API 404 独立识别 |

截图仅主动保存公开首页与已发布公开资料（`outputs/e2e/*/public-home.png`、`public-resident.png`），已查看手机首页和桌面公开资料；没有截管理密码、fragment、私密下载或凭据。自动 trace/video/失败截图关闭。测试服务为 8897 的临时独立 SQLite/identity，执行后退出并清理，不向最终用户库灌测试资料。

此结果不证明真实第三方 Agent 宿主、真实私密交付或排程已完成。最终组合、设计验收与专门独立代码审查由统筹另行固定范围；本页不替代这些结论。
